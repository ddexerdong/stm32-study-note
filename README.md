# STM32F103 HAL 学习笔记

> 这是基于野火 STM32F103 HAL 视频课程和官方 PDF 整理的个人学习笔记。
>
> 笔记偏工程复习、实验复现和排错，不替代官方手册、芯片数据手册或参考手册。

---

## 项目说明

这套笔记按课程实验顺序整理，重点不是复述资料，而是把每个外设实验整理成：

- 要解决的工程问题。
- CubeMX / MDK 配置步骤。
- HAL API 的最小使用框架。
- 调试方法和常见坑。
- 我自己的理解和复习检查清单。

所有引脚、模块型号、通信地址、波特率、PWM 通道、CAN 参数等，最终都以实际开发板原理图、CubeMX 配置和视频演示为准。

## 使用建议

1. 先按章节跑通最小实验，不要一开始就扩展复杂业务。
2. 每个实验先确认供电、共地、接线、CubeMX 配置和启动函数。
3. 遇到问题先查 [踩坑日记.md](stm32note/踩坑日记.md)，解决后把自己的新现象补进去。
4. 看到陌生名词先查 [STM32术语表.md](stm32note/STM32术语表.md)，再回到正文章节。
5. 所有引脚和参数以实际开发板原理图、CubeMX 配置和视频演示为准。

## 如何继续维护

1. 看完一集视频后，先在文件索引中找到对应课程编号。
2. 进入对应小节，处理本节的 `视频待核对` 项。
3. 只把视频确认过的接线、地址、波特率、寄存器、公式或协议写成确定内容。
4. 实测遇到的新问题补到 [踩坑日记.md](stm32note/踩坑日记.md)。
5. 新增或确认过的术语补到 [STM32术语表.md](stm32note/STM32术语表.md)。
6. 更新 [笔记完成报告.md](笔记完成报告.md) 或 [笔记后续补全待办.md](笔记后续补全待办.md) 的状态。
