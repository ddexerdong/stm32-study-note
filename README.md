>
> 原野火 STM32F103 HAL 视频编号仍可在 [[视频课程索引]] 中反查；重构前的完整笔记保留在 [[99_Archive_CourseNotes/README|课程笔记归档]]。

## 项目定位

这套笔记服务于四件事：

- 理解 STM32 芯片、时钟、中断和外设的真实关系。
- 用 CubeMX + HAL 搭建可复现的最小实验。
- 用波形、原始数据、HAL 返回值和回调分层排错。
- 把模块案例和项目逻辑组织成可维护的 BSP / App 结构。

## 如何维护

1. 学一个知识点，先更新对应能力文件。
2. 如果证据来自视频或实测，同步更新 [[视频实测核对表]]。
3. 遇到新问题，按“现象 -> 原因 -> 解决 -> 验证”补到 [[踩坑日记]]。
4. 出现新概念，在 [[STM32术语表]] 增加短定义和反向链接。
5. 新模块先复用现有总线和 bring-up 方法，不再把模块和芯片核心能力并列。
