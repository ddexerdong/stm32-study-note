| 公式 | 说明 | 章节 |
|------|------|------|
| `T = (PSC+1)(ARR+1) / TIMx_CLK` | 定时器溢出时间 | [17] |
| `f_PWM = TIMx_CLK / [(PSC+1)(ARR+1)]` | PWM 频率 | [23] |
| `Duty = CCR / (ARR+1) × 100%` | PWM 占空比 | [23] |
| `V = ADC值 / 4095 × 3.3` | ADC 读数转电压 | [21] |
| `R_LED = (VCC - V_LED) / I_LED` | LED 限流电阻 | [9] |

## 🔴 高频致命坑（新手必读）

1. **CubeMX 重新生成 → 用户代码被覆盖** — 所有代码必须写在 `/* USER CODE BEGIN */` / `/* USER CODE END */` 之间
2. **中断里调 `HAL_Delay()` → 程序卡死** — 中断里不能用阻塞延时，用标志位或 `HAL_GetTick()`
3. **定时器时间算不准** — APB1 分频 ≠ 1 时，定时器时钟自动 ×2（TIM2_CLK = 72MHz 不是 36MHz）
4. **串口 TX↔RX 接反** — 自己的 TX 接对方的 RX（交叉连接），且必须共地
5. **传感器/模块和 STM32 没共地** — GND 必须接在一起
6. **TIM + ADC 启动顺序反了** — 必须先启动 ADC+DMA，再启动 TIM 触发
