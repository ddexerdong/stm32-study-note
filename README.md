## 🔢 关键公式速查

| 公式 | 说明 |
|------|------|
| `T = (PSC+1)(ARR+1) / TIMx_CLK` | 定时器溢出时间 |
| `V = ADC值 / 4095 × 3.3` | ADC 读数转电压 |
| `f_PWM = TIMx_CLK / [(PSC+1)(ARR+1)]` | PWM 频率 |
| `Duty = CCR / (ARR+1) × 100%` | PWM 占空比 |
| `R_LED = (VCC - V_LED) / I_LED` | LED 限流电阻 |

## 🔴 高频致命坑（新手必看）

1. **CubeMX 重新生成 → 用户代码被覆盖** —— 所有代码必须写在 `/* USER CODE BEGIN */` 和 `/* USER CODE END */` 之间
2. **中断里调 `HAL_Delay()` → 程序卡死** —— 中断里不能用阻塞延时，用标志位或 `HAL_GetTick()`
3. **定时器时间算不准** —— APB1 分频 ≠ 1 时，定时器时钟自动 ×2（TIM2_CLK = 72MHz，不是 36MHz）
4. **串口 TX↔RX 接反** —— 自己的 TX 接对方的 RX（交叉连接），且必须共地
5. **传感器和 STM32 没共地** —— GND 必须接在一起
