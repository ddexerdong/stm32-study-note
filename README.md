## 核心公式

| 公式 | 说明 | 详见 |
|------|------|------|
| `T = (PSC + 1) x (ARR + 1) / TIMx_CLK` | 定时器溢出周期 | [03 中断与定时器](stm32note/03_中断与定时器.md) |
| `f_PWM = TIMx_CLK / [(PSC + 1) x (ARR + 1)]` | PWM 频率 | [06 定时器 PWM](stm32note/06_定时器PWM.md) |
| `Duty = CCR / (ARR + 1) x 100%` | PWM 占空比 | [06 定时器 PWM](stm32note/06_定时器PWM.md) |
| `V = ADC_Value / 4095 x 3.3` | ADC 值转电压 | [05 ADC 模数转换](stm32note/05_ADC模数转换.md) |
| `R_LED = (VCC - V_LED) / I_LED` | LED 限流电阻 | [02 GPIO 与传感器](stm32note/02_GPIO与传感器.md) |
| `Temp = (1.43 - V_sensor) / 0.0043 + 25` | F103 内部温度传感器典型换算 | [07 TIM 触发 ADC](stm32note/07_TIM触发ADC采集.md) |

## 高频工程原则

1. **用户代码写在 `USER CODE BEGIN/END` 之间**，否则 CubeMX 重新生成会覆盖。
2. **所有外部模块必须和 STM32 共地**。
3. **GPIO 不能直接驱动大电流负载**，蜂鸣器、电机、继电器要加驱动电路。
4. **中断里不要 `HAL_Delay()`、不要长时间 `printf()`**，复杂工作放主循环。
5. **TIM2/3/4 在 APB1 上，但常见配置下 TIMx_CLK = 72 MHz**，因为 APB1 分频后定时器时钟会 x2。
6. **多通道 ADC 优先用 DMA**，否则规则组 DR 结果容易被覆盖。
7. **串口先查 TX/RX 交叉、波特率、共地，再查代码**。
8. **TIM 触发 ADC 时，先启动 ADC，再启动 TIM**。
