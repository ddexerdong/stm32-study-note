# 通用调试方法

> 能力定位：用分层证据缩小问题范围，而不是随机改参数。

## 通用排查链

```text
供电
-> 共地
-> 接线与电平兼容
-> CubeMX 引脚/时钟/外设参数
-> 初始化函数
-> Start / Start_IT / Start_DMA
-> NVIC / DMA / 回调
-> HAL 返回值和状态寄存器
-> 原始数据
-> 协议与业务逻辑
```

## 最小化原则

1. 先跑单一外设最小实验。
2. 先看原始电平、波形、字节或 ADC 值。
3. 再加协议解析、公式和显示。
4. 每增加一层都保留可观察点。

## 工具选择

| 工具 | 适合的问题 |
|---|---|
| 万用表 | 供电、静态电平、共地 |
| 示波器 | 模拟波形、PWM、边沿质量、严格时序 |
| 逻辑分析仪 | UART/I2C/SPI/CAN 数字协议和时序 |
| 串口打印 | 状态、返回值、原始数据 |
| Debug/Watch | 控制流、变量、寄存器和回调 |
| DWT | 短代码运行时间和微秒计时 |

## 记录方法

把“现象、最小复现、原因、解决、验证”写入 [[踩坑日记]]；不要只记录最终改了哪个参数。

## 本节目标

- 建立可重复的分层排错流程。
- 根据问题类型选择万用表、串口、Debug、逻辑分析仪或示波器。
- 把每次故障沉淀为可复用记录。

## 知识地图

| 证据层 | 观察对象 | 常用工具 |
|---|---|---|
| 电源 | 电压、电流、纹波、共地 | 万用表/示波器 |
| 引脚 | 静态电平、边沿、复用 | 万用表/逻辑分析仪 |
| 外设 | HAL 返回值、状态、寄存器 | Debug/串口 |
| 传输 | 字节、帧、时序 | 逻辑分析仪 |
| 模拟 | AO、PWM、噪声 | 示波器 |
| 业务 | 状态机、协议、公式 | 日志/断点/测试数据 |

## 本质理解

调试不是猜参数，而是不断回答“上一层是否已经有证据证明正常”。如果 I2C 地址都不 ACK，就不应该调传感器算法；如果 PWM 引脚没有波形，就不应该先怀疑电机机械结构。

## 总体排查顺序

```text
供电
-> 共地
-> 原理图与接线
-> 电平兼容
-> CubeMX 时钟/引脚/外设
-> MX_xxx_Init
-> HAL Start API
-> NVIC/DMA/Callback
-> 原始波形/字节/数值
-> 协议/公式/业务
```

## 工具怎么用

- 万用表：测 VCC/GND、静态 GPIO、分压和短路，不适合观察高速时序。
- 串口打印：输出 HAL 返回值、状态、长度和原始数据；中断里不要大量打印。
- 断点/Watch：确认控制流、句柄 State、回调和变量生命周期。
- 逻辑分析仪：解码 UART/I2C/SPI/CAN，确认地址、ACK、边沿和帧。
- 示波器：观察 PWM、模拟噪声、上升时间、严格脉宽和供电纹波。

## 各外设调试重点

| 外设 | 第一观察点 | 第二观察点 |
|---|---|---|
| GPIO | 真实引脚电压 | 模式/有效电平 |
| USART | TX/RX 波形与波特率 | 原始 HEX/帧边界 |
| ADC | 万用表 AO 电压 | raw/VREF/采样时间 |
| TIM/PWM | 频率和脉宽 | TIMx_CLK/PSC/ARR/CCR |
| I2C | 空闲高电平和 ACK | 地址/寄存器/返回值 |
| SPI | CS 和模式 | 命令/地址/Busy |
| CAN | 收发器/CANH/CANL | 位时序/ACK/过滤器 |
| RS485 | DE/RE 与 A/B | TC 后切换/协议 |
| 模块 | ID/原始数据 | 换算/算法/显示 |

## 最小诊断代码

> 代码性质：示例框架，用于理解调用顺序，不能保证直接编译。

```c
HAL_StatusTypeDef status = HAL_I2C_IsDeviceReady(&hi2c1, device_addr, 2, 20);
printf("status=%d state=%d error=0x%08lx\r\n",
       status, HAL_I2C_GetState(&hi2c1), HAL_I2C_GetError(&hi2c1));
```

## 常见坑

| 坑 | 后果 | 改进 |
|---|---|---|
| 一次改多个参数 | 无法知道哪个修改有效 | 单变量实验 |
| 只看最终显示 | 中间层故障不可见 | 保留 raw/状态日志 |
| 中断里打印 | 时序和实时性被破坏 | 置标志后主循环打印 |
| 不记录版本/配置 | 问题无法复现 | 保存 `.ioc`、日志和 Git 提交 |
| 先套网上代码 | 硬件/版本不匹配 | 先查手册和最小实验 |
