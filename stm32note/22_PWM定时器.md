# 22-23 定时器 PWM 输出

## 先记住一句话

PWM 本质上是“用固定频率的方波，通过改变高电平持续时间来控制平均输出效果”。

## PWM 基本概念

```
PWM = Pulse Width Modulation（脉冲宽度调制）

一个周期内：
┌──┐    ┌──┐    ┌──
│  │    │  │    │
┘  └────┘  └────┘
|<-- T -->|
|<-- 高电平时间 -->|
    |<-- 一个周期计数范围 ARR+1 -->|

频率 = 1/T
占空比 = 高电平时间 / 周期 × 100%
```

### 寄存器概念：CNT、PSC、ARR、CCR ⭐

| 寄存器 | 名称 | 功能 | 取值范围 | 作用 |
|-------|------|------|--------|------|
| **CNT** | 计数器 | 定时器当前计数值，每个时钟周期自增 1 | 0 ~ ARR | 通过 CNT 与 CCR 比较来产生 PWM 波形 |
| **PSC** | 预分频寄存器 | 降低计时速率，每计 (PSC+1) 个输入时钟才让 CNT 加 1 | 0 ~ 65535 | 决定定时器的计时速度，影响 PWM 频率 |
| **ARR** | 自动重装寄存器 | 定义计数周期，CNT 计到 ARR 后自动重置为 0 | 0 ~ 65535 | 决定 PWM 的周期，影响 PWM 频率 |
| **CCR** | 比较寄存器 | PWM 占空比的控制点，CNT < CCR 时输出高电平，CNT ≥ CCR 时输出低电平 | 0 ~ ARR | 决定 PWM 的占空比（高电平持续时间） |

**核心工作流程：**
```
1. 时钟进入定时器
   ↓
2. 分频处理 (预分频系数 PSC+1)
   ↓
3. CNT 计数 (0 → ARR 循环)
   ↓
4. CNT 与 CCR 比较 → 输出 PWM 信号
   - CNT < CCR  → 输出高电平 ✓
   - CNT ≥ CCR  → 输出低电平 ✗
```

**四者之间的数学关系：**
- **PWM周期** = (ARR + 1) × (PSC + 1) / TIMx_CLK
- **PWM频率** = TIMx_CLK / [(ARR + 1) × (PSC + 1)]
- **PWM占空比** = CCR / (ARR + 1) × 100%
- **高电平持续时间** = CCR × (PSC + 1) / TIMx_CLK

**配置约束：**
- PSC 和 ARR 都是"从 0 开始计数"，所以产生的周期是 (ARR + 1) × (PSC + 1)
- CCR 必须在 [0, ARR] 范围内，超出此范围占空比会异常
- 通常 CCR = 0 时占空比为 0%（持续低电平），CCR = ARR 时占空比约为 100%（持续高电平）

### 公式 ⭐

```
PWM频率  = TIMx_CLK / [(PSC+1) × (ARR+1)]
PWM占空比 = CCR / (ARR+1) × 100%

说明：
- PSC 和 ARR 都是“从 0 开始计数”，所以公式里要加 1。
- TIMx_CLK 不一定等于系统时钟，若 APB 预分频不为 1，定时器时钟可能会翻倍，实际配置前要看时钟树。

例：1kHz PWM，72MHz 定时器时钟
PSC = 71，ARR = 999
频率 = 72M / (72 × 1000) = 1kHz
占空比 50% → CCR = 500
```

## HAL PWM 函数

```c
// 启动PWM（通常在初始化后、main函数中调用）
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

// 动态修改占空比（在 while 或回调中）
// CCR 取值范围通常是 0 ~ ARR
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 500);  // 50%

// 停止PWM
HAL_TIM_PWM_Stop(&htim3, TIM_CHANNEL_1);
```

## 呼吸灯实现

```c
// 在 while(1) 中
// 渐亮
for(uint16_t duty = 0; duty <= 1000; duty++) {
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
    HAL_Delay(1);
}
// 渐灭
for(uint16_t duty = 1000; duty > 0; duty--) {
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
    HAL_Delay(1);
}
```

## 通用定时器 vs 高级定时器

| | 通用定时器（TIM2-5） | 高级定时器（TIM1/8） |
|--|---------------------|---------------------|
| PWM通道 | 通常 4 个 | 4 个 + 互补输出 |
| 互补输出 | ❌ | ✅（用于电机驱动） |
| 死区时间 | ❌ | ✅（防止上下管同时导通） |
| 刹车输入 | ❌ | ✅ |
| 适用 | LED、舵机、一般 PWM | 无刷电机、逆变器 |

## CubeMX 配置步骤

1. Timers → TIM3 → Channel1: PWM Generation CH1
2. 填写 PSC 和 ARR（决定频率）
3. Pulse = 初始 CCR 值（决定初始占空比）
4. GPIO 会自动切到复用推挽输出，一般不需要手动改模式
5. 普通 PWM 不需要开 NVIC，只有你要做中断/回调扩展时才考虑开启

## 舵机控制（扩展）

常见舵机约为 1ms ~ 2ms 对应有效角度范围，部分型号可扩展到 0.5ms ~ 2.5ms。

```
舵机PWM：50Hz（周期20ms）

    0° → 高电平 0.5ms → 占空比 2.5%
90° → 高电平 1.5ms → 占空比 7.5%
180°→ 高电平 2.5ms → 占空比 12.5%

ARR = 19999，PSC = 71（72MHz 下）
0°  → CCR = 500
90° → CCR = 1500
180°→ CCR = 2500

注意：很多舵机对高电平脉宽敏感，先从 1000us ~ 2000us 试起更稳妥，不要一上来就把范围拉满。
```

## 踩坑记录

- PWM 引脚要选复用推挽输出，CubeMX 里选了 PWM Generation 后通常会自动配置，但仍要核对引脚是否和外设通道匹配。
- TIM3 的 CH1 常见对应 PA6，CH2 对应 PA7，但具体还要看芯片型号和重映射配置，不要只记死表。
- 占空比不是“电压百分比”，它只是高电平时间比例；对 LED、舵机、蜂鸣器的效果不同，别混淆。
- 舵机不要直接理解成“角度 = 占空比线性对应”，实际是脉宽控制，更关注高电平持续时间。
