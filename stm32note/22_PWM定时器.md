# 22-23 定时器 PWM 输出

> PWM 是控制 LED 亮度、舵机角度、电机转速的核心技术。本质就是用方波的「高电平占比」来控制平均输出效果。

---

## 一句话理解 PWM

> PWM 不是改变电压，是用**固定频率的方波，改变高电平持续时间**来骗过人眼/电机，产生「亮度不同」「角度不同」「转速不同」的效果。

---

## 寄存器概念速览

> TL;DR：你不用死记这四个寄存器。**PSC + ARR 决定频率，CCR 决定占空比**。记住这一句就够了，用到时再查下面的细节。

| 寄存器 | 一句话 | 取值范围 | 作用 |
|-------|--------|--------|------|
| **PSC** | 预分频，降速用 | 0~65535 | 定时器时钟 ÷ (PSC+1) = 计数频率 |
| **ARR** | 计数上限，周期 | 0~65535 | 计到 ARR 从头来，决定周期 |
| **CNT** | 当前计数值 | 0~ARR | 一直在 0 到 ARR 之间循环 |
| **CCR** | 比较值，占空比 | 0~ARR | CNT < CCR 时高电平，CNT ≥ CCR 时低电平 |

```
时钟 → 预分频(PSC) → CNT 计数(0→ARR 循环) → CNT 与 CCR 比较 → 输出 PWM
                                                 ├→ CNT < CCR: 高电平
                                                 └→ CNT ≥ CCR: 低电平
```

### 三个公式 ⭐

```
PWM 频率   = TIMx_CLK / [(PSC + 1) × (ARR + 1)]
PWM 占空比  = CCR / (ARR + 1) × 100%
高电平时间  = CCR × (PSC + 1) / TIMx_CLK

例：1kHz PWM，TIMx_CLK = 72MHz
选 PSC = 71, ARR = 999
频率 = 72M / (72 × 1000) = 1kHz ✓
占空比 50% → CCR = 500
```

> 💡 PSC 和 ARR 因为"从 0 开始计数"，实际上都是 N+1 的效果，公式里必须加 1。

---

## PWM 模式 1 vs 模式 2

| 模式 | 行为 | 默认 |
|------|------|------|
| **PWM Mode 1** | CNT < CCR 时高电平，CNT ≥ CCR 时低电平 | ⭐ 常用 |
| **PWM Mode 2** | CNT < CCR 时低电平，CNT ≥ CCR 时高电平 | 少用 |

> 99% 的场景用模式 1，不用纠结。

---

## HAL PWM 函数

```c
// 启动 PWM（在初始化后、main() 中调用）
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

// 动态修改占空比（在 while(1) 或回调中）
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 500);  // 50% 占空比

// 停止 PWM
HAL_TIM_PWM_Stop(&htim3, TIM_CHANNEL_1);
```

---

## CubeMX 配置步骤

1. **Timers** → **TIM3** → Channel1: **PWM Generation CH1**
2. 填写 PSC 和 ARR（决定频率）
3. Pulse = 初始 CCR 值（决定启动时的占空比，可以填 0）
4. GPIO 会自动切到复用推挽输出，**核对引脚是否和外设通道匹配**：
   - TIM3_CH1 常见对应 **PA6**，CH2→PA7（具体看芯片数据手册）
5. 普通 PWM **不需要开 NVIC**（除非要做中断回调）

> ⚠️ CubeMX 选了 PWM Generation 后 GPIO 通常自动配好。但换芯片型号后引脚映射可能不同，别死记。

## 呼吸灯实现

```c
// 在 while(1) 中
// 渐亮
for (uint16_t duty = 0; duty <= 1000; duty++)
{
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
    HAL_Delay(1);
}
// 渐灭
for (uint16_t duty = 1000; duty > 0; duty--)
{
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
    HAL_Delay(1);
}
```

> 💡 这是教学写法，会用 `HAL_Delay` 阻塞 CPU 约 2 秒。更好的做法是把呼吸灯状态机放进定时器中断里，CPU 可以同时干别的事。

## 通用定时器 vs 高级定时器

| | 通用定时器（TIM2~5） | 高级定时器（TIM1/8） |
|--|---------------------|---------------------|
| PWM 通道数 | 4 个 | 4 个 + 3 个互补输出 |
| 互补输出 | ❌ | ✅（一对相反信号，电机半桥驱动） |
| 死区时间 | ❌ | ✅（防止上下管同时导通短路） |
| 刹车功能 | ❌ | ✅（紧急制动输入） |
| 适用场景 | LED、舵机、简单调速 | 无刷电机、逆变器 |

## 舵机控制（扩展）

### 原理

常见舵机用 50Hz（周期 = 20ms）的 PWM 信号，**高电平持续时间**决定角度：

```
50Hz → 周期 20ms → ARR = 19999（PSC=71, 72MHz 下）

角度    高电平脉宽    占空比    CCR 值
 0° →    0.5ms  →   2.5%  →   500
90° →    1.5ms  →   7.5%  →   1500
180°→    2.5ms  →  12.5%  →   2500
```

### 🔴 舵机安全警告

- **不同舵机的高电平范围不同**。先从小范围（1000μs ~ 2000μs，即 1000~2000 CCR）试起。
- **不要一上来就拉到极限**（0.5ms / 2.5ms），有些舵机机械结构会堵转甚至烧电机。
- 舵机控制的本质是**脉宽（高电平时间）**，不是占空比百分比。别把"占空比 7.5%"理解成"角度 7.5%"，它们没有线性对应关系。

## 频率选择参考

| 场景 | 推荐频率 | 原因 |
|------|---------|------|
| LED 调光 | 1kHz+ | 高于人眼闪烁感知频率 |
| 舵机 | 50Hz | 舵机协议标准 |
| 直流电机调速 | 10~20kHz | 避开人耳听觉范围（不然电机啸叫） |
| 无源蜂鸣器 | 1~5kHz | 人耳敏感范围，不同频率 = 不同音调 |

## 踩坑记录

- [ ] PWM 引脚没输出 → CubeMX 是不是没选 PWM Generation？通道是不是对应的引脚？
- [ ] 占空比不对 → CCR 值是否超出了 ARR 范围？（CCR 必须 ≤ ARR）
- [ ] `__HAL_TIM_SET_COMPARE` 改占空比没生效 → 通道号写对了吗？定时器启动了吗？
- [ ] 舵机抖动严重或不转 → 供电不足（舵机电流大，不能从 ST-Link 的 3.3V 供电，需外接电源）
- [ ] 电机驱动时芯片发烫 → 驱动器没加续流二极管/电流过大（功率设备必须隔离驱动）
