## STM32命名规则

```
STM32 F 103 C 8 T 6
 │     │  │  │ │ │ └─ 温度范围（6 = 工业级）
 │     │  │  │ │ └─── 封装（T = LQFP）
 │     │  │  │ └───── Flash大小（8 = 64KB）
 │     │  │  └─────── 引脚数（C = 48pin）
 │     │  └────────── 子系列（103 = 基本型）
 │     └──────────── 系列（F = 通用）
 └────────────────── ST公司产品线
```

## CubeMX新建工程流程

1. 选芯片型号（STM32F103C8T6）
2. 配置时钟树 ⭐
3. 配置需要的外设（GPIO / UART / TIM…）
4. 生成代码 → 用CubeIDE打开

## 时钟树（重点）

```
HSE（8MHz外部晶振）
    └→ PLL（×9）→ SYSCLK = 72MHz
                      ├→ AHB（HCLK）= 72MHz  → GPIO、DMA
                      ├→ APB1（PCLK1）= 36MHz → TIM2/3/4、UART2/3、SPI2
                      └→ APB2（PCLK2）= 72MHz → TIM1、UART1、SPI1、ADC
```

> ⚠️ APB1最大36MHz，APB2最大72MHz，配置时注意分频
