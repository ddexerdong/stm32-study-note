## 工具链

### 需要安装的工具

| 工具 | 下载来源 | 用途 |
|------|---------|------|
| STM32CubeIDE | [st.com](https://www.st.com) 搜索 CubeIDE | 编写/编译/烧录/调试 |
| STM32CubeMX | CubeIDE 已内置 | 图形化配置外设和时钟 |
| ST-Link 驱动 | CubeIDE 安装包自带 | 烧录器与电脑通信 |
| 串口调试助手 | 任意（推荐 SSCOM / CuteCom） | 查看 printf 输出 |

### 安装注意事项

- **安装路径不要有中文**，否则某些工具链组件可能找不到文件。
- Mac 用户：CubeIDE 安装后需额外安装芯片支持包（Help → Manage Embedded Software Packages → 勾选 STM32F1）。
- 装完后插上 ST-Link / 开发板，在设备管理器里确认有 ST-Link 设备。

## STM32 命名规则

读懂芯片型号，买板子/查手册时不会买错：

```
STM32 F 103 C 8 T 6
 │     │  │  │ │ │ └─ 温度范围（6 = 工业级 -40~85℃）
 │     │  │  │ │ └─── 封装（T = LQFP）
 │     │  │  │ └───── Flash 大小（8 = 64KB）
 │     │  │  └─────── 引脚数（C = 48pin）
 │     │  └────────── 子系列（103 = 基本型、F1 系列）
 │     └──────────── 系列（F = 通用型）
 └────────────────── ST 产品线
```

> 本笔记默认使用 **STM32F103C8T6**（俗称 C8T6 最小系统板 / BluePill），主频 72MHz，Flash 64KB，RAM 20KB。

## CubeMX 新建工程流程

1. **选芯片**：Commercial Part Number 输入 `STM32F103C8T6` → 双击选中
2. **配置调试口**：System Core → SYS → Debug → **Serial Wire**（否则烧录口被禁用，烧不进去！）
3. **配置时钟树** ⭐（见下一节）
4. **配置外设**：GPIO / UART / TIM / ADC...按需开启
5. **生成代码**：Project Manager 标签 → 填工程名 → Toolchain 选 STM32CubeIDE → **勾选 "Generate peripheral initialization as a pair of .c/.h files"** → 点 GENERATE CODE

## 时钟树（重点）⭐

### 配置步骤

在 CubeMX 的 **Clock Configuration** 标签里：

1. **HSE** 选 `Crystal/Ceramic Resonator`（外部晶振）
2. **PLL Source Mux** 选 HSE
3. **PLL Mul** 设为 `×9`
4. 回车让工具自动计算分频 → 确认以下数值：

```
HSE（8MHz 外部晶振）
    └→ PLL（×9）→ SYSCLK = 72MHz
                      ├→ AHB Prescaler = /1  → HCLK = 72MHz   → GPIO、DMA、SDIO
                      ├→ APB1 Prescaler = /2 → PCLK1 = 36MHz  → TIM2/3/4、UART2/3、SPI2/I2C2
                      └→ APB2 Prescaler = /1 → PCLK2 = 72MHz  → TIM1、UART1、SPI1、ADC1
```

### 关键约束

| 总线 | 最大频率 | 接了哪些外设 |
|------|---------|------------|
| APB1 | 36MHz | 普通定时器（TIM2~TIM7）、USART2/3、SPI2、I2C |
| APB2 | 72MHz | 高级定时器（TIM1/8）、USART1、SPI1、ADC、GPIO |

> ⚠️ **定时器时钟坑**：如果 APBx 的分频系数 **≠ 1**，则定时器时钟 = APBx 时钟 × 2。
> 例：APB1 = 36MHz（分频 = /2 ≠ 1）→ TIM2_CLK = 36 × 2 = **72MHz**。这是新手算错定时时间的头号原因。

## 生成代码后的项目结构

第一次打开项目，你只需要认识这几个文件：

```
项目根目录/
├── Core/
│   ├── Inc/
│   │   └── main.h          ← 全局声明，一般不用改
│   └── Src/
│       └── main.c          ← ⭐ 你的代码主要写在这
├── Drivers/                ← HAL 库代码，不要改
├── .ioc                    ← CubeMX 配置文件（双击可重新配置）
└── STM32F103C8Tx_FLASH.ld  ← 链接脚本，不用管
```

### 🔴 最重要的规则

CubeMX 重新生成代码时，**只有写在下面这对注释之间的代码才会保留**：

```c
/* USER CODE BEGIN xxx */
// 你的代码写在这里 ✅
/* USER CODE END xxx */
```

写在注释外面的代码，重新生成后会被覆盖掉！新手丢代码的头号原因。

## 烧录验证：第一个 LED 闪烁

### CubeMX 配置

1. Pinout 标签 → 点 **PC13** → 选 `GPIO_Output`（C8T6 最小系统板通常 PC13 连着板载 LED）
2. 生成代码

### 在 main.c 的 while(1) 中添加

```c
/* USER CODE BEGIN WHILE */
while (1)
{
    HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
    HAL_Delay(500);
    /* USER CODE END WHILE */
}
```

### 编译烧录

1. 工具栏点 🔨（Build）→ 确认 0 errors
2. 点 ▶️（Debug）或 🚀（Run）→ ST-Link 自动烧录
3. 板载 LED 开始闪烁 → **环境搭建成功！**

## 常见启动问题

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| 烧录不进去 | Debug 口没配成 Serial Wire | CubeMX → SYS → Debug 选 Serial Wire |
| 烧录进去了但程序不跑 | BOOT0 没接地 | BOOT0 通过 10kΩ 电阻接 GND（从 Flash 启动） |
| 编译报错 "undefined reference" | 库文件缺失 | 检查 CubeMX → Project Manager → 外设初始化选项 |
| LED 不亮 | PC13 是低电平点亮 | 确认板子原理图（有些板子 LED 是低电平驱动） |
