# MPU6050 姿态传感器

> 模块定位：用 I2C 寄存器读写完成六轴传感器基础 bring-up。
>
> 原始来源：[[12_I2C传感器]]。

## 基础主线

```text
地址 ACK
-> 读 WHO_AM_I
-> 解除睡眠
-> 配置加速度/陀螺仪量程
-> 连续读取原始数据
-> 按量程换算
-> 串口或 OLED 显示
```

## 边界

基础实验只要求原始加速度、角速度和温度数据可信。姿态角通常还涉及滤波、融合或 DMP，不能把“读寄存器”直接等同于“得到姿态”。

> 视频待核对：模块地址、WHO_AM_I、寄存器宏、量程、换算比例、连续读取封装和课程是否涉及姿态融合。

## 本节目标

- 能完成设备识别、唤醒、量程配置和原始六轴读取。
- 能正确拼接多字节原始值，并把换算参数与手册版本绑定。
- 能区分原始传感器数据和姿态融合结果。

## 模块作用

读取三轴加速度、三轴角速度和温度原始数据，建立 IMU 寄存器驱动与换算流程。

## 知识地图

| 名词 | 工程含义 |
|---|---|
| 加速度计 | 测量比力/重力方向 |
| 陀螺仪 | 测量角速度 |
| WHO_AM_I | 设备身份寄存器 |
| 睡眠位 | 上电后需解除低功耗状态 |
| 量程比例 | 原始 LSB 到工程单位的换算依据 |

## 本质理解

模块驱动不是“抄一份初始化代码”，而是把硬件连接、总线事务、状态、原始数据和业务结果逐层验证。任何上层结果都必须建立在下层证据可靠的基础上。

## 硬件连接关系

- I2C SCL/SDA 和共地
- 模块地址脚状态决定地址，需实测/查原理图
- 中断脚可选，基础读取不依赖
- 模块电平和上拉需兼容

## 通信 / 控制链路

```text
扫描地址
-> 读 WHO_AM_I
-> 解除睡眠
-> 配置量程/滤波
-> 连续读取 14 字节类原始块
-> 拼接 int16
-> 按量程换算
-> 静态姿态校验
```

## CubeMX 配置要点

1. 启用 I2C
2. 先阻塞 API 读 WHO_AM_I
3. 串口打印原始数据
4. 需要数据中断时再配置 EXTI

## 本模块依赖的 HAL 层

| 模块动作 | 依赖 HAL | 说明 |
|---|---|---|
| 探测 I2C 地址 | `HAL_I2C_IsDeviceReady()` | 确认 ACK；地址表达方式按 HAL 和驱动宏统一 |
| 读取 WHO_AM_I/状态/连续原始值 | `HAL_I2C_Mem_Read()` | 明确寄存器地址宽度、读取长度和多字节顺序 |
| 解除睡眠、配置量程/滤波 | `HAL_I2C_Mem_Write()` | 每次写入检查 `HAL_OK`，必要时读回确认 |
| 数据就绪中断 | `HAL_GPIO_EXTI_Callback()` | 可选；只发布“数据可读”事件，不在回调中做完整 I2C 读取和姿态计算 |
| 打印原始六轴值 | `HAL_UART_Transmit()` 或 `printf` | 用于先证明原始数据变化，再接换算/融合 |

HAL 只负责 I2C 和可选 EXTI。寄存器值、量程比例、温度公式和姿态融合算法属于 MPU6050 手册/算法层，不能由 HAL API 推导。

### 典型调用顺序

```text
MX_I2Cx_Init()
-> HAL_I2C_IsDeviceReady()
-> HAL_I2C_Mem_Read() 核对 WHO_AM_I
-> HAL_I2C_Mem_Write() 解除睡眠并写最少配置
-> 连续 HAL_I2C_Mem_Read() 读取原始字节
-> 拼接有符号值
-> 按已核对量程换算并输出
```

### 什么时候用哪个函数？

| 场景 | 推荐函数 |
|---|---|
| 地址 bring-up | `HAL_I2C_IsDeviceReady()` |
| 读 ID/原始寄存器 | `HAL_I2C_Mem_Read()` |
| 写工作模式/量程 | `HAL_I2C_Mem_Write()` |
| 按数据就绪事件采样 | EXTI 回调置标志，主循环执行 I2C 读取 |

## Bring-up 顺序

1. 只验证供电、共地和静态电平。
2. 只验证 GPIO/总线和 HAL 返回值。
3. 读取 ID、DO、原始字节或原始 ADC 值。
4. 加入最少配置，保留每一步返回值。
5. 原始数据稳定后再换算、滤波和显示。
6. 最后加入业务状态机和异常恢复。

## 最小驱动框架

> 代码性质：示例框架，用于理解流程，不能保证直接编译。

```c
uint8_t MPU6050_ReadRaw(MPU6050_Raw_t *raw)
{
    uint8_t buf[MPU6050_RAW_BYTES];
    if (HAL_I2C_Mem_Read(&hi2c1, MPU6050_ADDR, MPU6050_DATA_REG,
                         I2C_MEMADD_SIZE_8BIT, buf, sizeof(buf), 100) != HAL_OK) return 0;
    return MPU6050_DecodeRaw(buf, raw);
}
```

## 常见坑

| 现象 | 常见原因 | 处理方法 |
|---|---|---|
| ID 不对 | 地址/寄存器/左移错误 | 扫描并读单寄存器 |
| 原始值不变 | 未解除睡眠 | 检查电源管理配置 |
| 符号错误 | 高低字节/符号拼接错 | 打印单字节再组合 |
| 换算离谱 | 量程与比例不一致 | 按同一配置计算 |
| 姿态漂移 | 把原始值直接积分 | 需要校准和融合 |
