# 蜂鸣器与简单执行器

> 模块定位：用 GPIO/PWM 驱动低复杂度执行器，并建立电流与有效电平意识。
>
> 原始来源：[[02_GPIO与传感器]]。

## 有源与无源蜂鸣器

- 有源蜂鸣器内部带振荡，通常用开关电平控制。
- 无源蜂鸣器需要 PWM 产生音调。
- GPIO 电流能力有限，负载可能需要三极管、MOS 或驱动芯片。

## 工程检查

```text
负载供电
-> 共地
-> 驱动级
-> GPIO/PWM 引脚
-> 有效电平
-> 启动函数
-> 业务逻辑
```

LED、蜂鸣器和舵机的实际引脚、供电和有效电平以实际开发板原理图和 CubeMX 配置为准。

## 本节目标

- 能区分有源/无源蜂鸣器及 GPIO/PWM 控制方式。
- 能判断负载是否需要三极管、MOS 或专用驱动。
- 能安全完成低电流执行器的最小控制实验。

## 模块作用

把 GPIO/PWM 控制扩展到蜂鸣器、LED、继电器、风扇等执行器，并建立电流和反向电动势意识。

## 知识地图

| 名词 | 工程含义 |
|---|---|
| 有源蜂鸣器 | 内部振荡，开关电平即可响 |
| 无源蜂鸣器 | 需要 PWM 音调 |
| 驱动级 | 三极管/MOS/专用驱动承担负载电流 |
| 续流保护 | 感性负载断电时吸收反向能量 |
| 有效电平 | 模块使能逻辑需实测 |

## 本质理解

模块驱动不是“抄一份初始化代码”，而是把硬件连接、总线事务、状态、原始数据和业务结果逐层验证。任何上层结果都必须建立在下层证据可靠的基础上。

## 硬件连接关系

- GPIO 不直接驱动大电流负载
- 驱动级和 STM32 必须有可靠参考地
- 继电器/电机/风扇按感性负载设计保护
- 无源蜂鸣器接 TIM PWM 通道

## 通信 / 控制链路

```text
断开负载验证控制脚
-> 检查驱动级和供电
-> 低功率连接负载
-> 验证有效电平
-> 再增加 PWM/业务状态机
```

## CubeMX 配置要点

1. 有源蜂鸣器/继电器控制脚配 GPIO_Output
2. 无源蜂鸣器配 TIM PWM
3. 设置安全的上电默认电平
4. 需要渐变/音调时计算 PSC/ARR/CCR

## 本模块依赖的 HAL 层

| 模块动作 | 依赖 HAL | 说明 |
|---|---|---|
| 有源蜂鸣器/继电器开关 | `HAL_GPIO_WritePin()` | GPIO 只控制驱动级，不直接承担大电流负载 |
| 最小翻转验证 | `HAL_GPIO_TogglePin()` | 适合低速确认，不适合音调或精确时序 |
| 启动无源蜂鸣器/PWM | `HAL_TIM_PWM_Start()` | TIM 通道、复用引脚和驱动电路已配置 |
| 改音量/占空比或控制量 | `__HAL_TIM_SET_COMPARE()` | 限制 CCR 范围；频率和占空比作用需按负载理解 |
| 改音调频率 | 修改 TIM PSC/ARR 或重新配置 | 应在安全时机更新并理解预装载，不用 GPIO 延时模拟高质量音调 |

### 典型调用顺序

```text
确认负载类型和驱动级
-> GPIO 输出安全默认态
-> 有源器件直接 WritePin 开关
-> 无源器件初始化 TIM PWM
-> HAL_TIM_PWM_Start()
-> 设置频率和 CCR
```

### 什么时候用哪个函数？

| 场景 | 推荐函数 |
|---|---|
| 有源蜂鸣器/继电器开关 | `HAL_GPIO_WritePin()` |
| 无源蜂鸣器发声/调音 | TIM PWM + Compare/周期配置 |
| 大电流风扇/电机 | GPIO/PWM 只驱动三极管、MOS 或驱动芯片 |

## Bring-up 顺序

1. 只验证供电、共地和静态电平。
2. 只验证 GPIO/总线和 HAL 返回值。
3. 读取 ID、DO、原始字节或原始 ADC 值。
4. 加入最少配置，保留每一步返回值。
5. 原始数据稳定后再换算、滤波和显示。
6. 最后加入业务状态机和异常恢复。

## 最小驱动框架

> 代码性质：示例框架，用于理解调用顺序，不能保证直接编译。

```c
typedef struct
{
    GPIO_TypeDef *port;
    uint16_t pin;
    GPIO_PinState on_level;
} GpioActuator_t;

static void Actuator_Set(const GpioActuator_t *actuator, uint8_t enabled)
{
    GPIO_PinState level = enabled ? actuator->on_level :
                          (actuator->on_level == GPIO_PIN_SET ?
                           GPIO_PIN_RESET : GPIO_PIN_SET);
    HAL_GPIO_WritePin(actuator->port, actuator->pin, level);
}

static uint8_t PassiveBuzzer_Start(uint32_t compare)
{
    if (HAL_TIM_PWM_Start(&htim3, BUZZER_TIM_CHANNEL) != HAL_OK)
    {
        return 0U;
    }
    __HAL_TIM_SET_COMPARE(&htim3, BUZZER_TIM_CHANNEL, compare);
    return 1U;
}

static void PassiveBuzzer_Stop(void)
{
    __HAL_TIM_SET_COMPARE(&htim3, BUZZER_TIM_CHANNEL, 0U);
    (void)HAL_TIM_PWM_Stop(&htim3, BUZZER_TIM_CHANNEL);
}

GpioActuator_t active_buzzer = {
    .port = BUZZER_GPIO_Port,
    .pin = BUZZER_Pin,
    .on_level = BUZZER_ON_LEVEL,
};

void Alarm_SetMode(AlarmMode_t mode)
{
    if (mode == ALARM_ACTIVE_BUZZER)
        Actuator_Set(&active_buzzer, 1U);
    else if (mode == ALARM_PASSIVE_BUZZER)
        (void)PassiveBuzzer_Start(BUZZER_COMPARE_TICKS);
    else
    {
        Actuator_Set(&active_buzzer, 0U);
        PassiveBuzzer_Stop();
    }
}
```

有源/无源类型、有效电平、PWM 频率和驱动级以模块手册与原理图为准。GPIO 不能直接驱动超出其电流能力的蜂鸣器、继电器、风扇或电机。

## 常见坑

| 现象 | 常见原因 | 处理方法 |
|---|---|---|
| GPIO 发热/复位 | 直接带大电流 | 增加驱动级和独立供电 |
| 蜂鸣器不响 | 有源/无源判断错 | 确认型号并选择 GPIO/PWM |
| 继电器干扰 MCU | 无续流/电源耦合 | 加保护和去耦 |
| 上电误动作 | 默认电平不安全 | 初始化前设计上拉/下拉 |
| PWM 有波形但无声 | 频率/负载连接不符 | 示波器确认并按型号调整 |
