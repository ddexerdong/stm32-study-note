# 数字传感器与 LM393

> 模块定位：把光敏、反射、热敏、火焰等比较器模块统一为数字输入案例。
>
> 原始来源：[[02_GPIO与传感器]]、[[05_ADC模数转换]]。

## 通用结构

```text
传感元件产生模拟变化
-> 模块电位器设置比较阈值
-> LM393 输出 DO 高/低电平
-> STM32 GPIO 读取
-> 业务层控制 LED 或蜂鸣器
```

## DO 与 AO

- DO 只表示是否越过阈值，不代表连续物理量。
- AO 是模拟电压，应交给 [[ADC与模拟采样]]。
- 有效电平、阈值方向和模块供电不能凭模块名称猜测。

## 模块差异

| 模块 | 主要变量 | 特有风险 |
|---|---|---|
| 光敏 | 环境光 | 阈值和场景相关 |
| 反射 | 距离、表面颜色、环境光 | 输出容易抖动 |
| 热敏 | 温度变化 | 响应较慢，DO 不是温度值 |
| 火焰 | 特定光谱响应 | 只做低风险教学测试 |

## 调试

先打印 DO 原始电平，再决定是否取反；调节阈值时同时观察模块指示灯和 GPIO 读数。

> 视频待核对：课程模块型号、接线、有效电平、阈值方向和安全测试方式。

## 本节目标

- 能用统一模型区分 LM393 模块的 DO 与 AO。
- 能先实测有效电平，再选择 GPIO 或 ADC 读取。
- 能按供电、阈值、原始信号和业务逻辑分层排错。

## 模块作用

用比较器把连续传感信号转换成阈值型数字输入；同时保留 AO 供 ADC 观察连续变化。

## 知识地图

| 名词 | 工程含义 |
|---|---|
| LM393 | 双比较器，把传感电压与阈值比较 |
| DO | 比较后的数字输出 |
| AO | 连续模拟电压输出 |
| 阈值电位器 | 调整比较基准 |
| 有效电平 | 触发时 DO 是高还是低，需实测 |

## 本质理解

模块驱动不是“抄一份初始化代码”，而是把硬件连接、总线事务、状态、原始数据和业务结果逐层验证。任何上层结果都必须建立在下层证据可靠的基础上。

## 硬件连接关系

- VCC/GND 按模块额定电压并与 STM32 共地
- DO 接普通 GPIO 输入
- AO 仅接支持 ADC 的 Analog 引脚
- LED/蜂鸣器由独立输出脚或驱动级控制

## 通信 / 控制链路

```text
确认供电/共地
-> 串口打印 DO
-> 调电位器观察翻转
-> 读取 AO 原始值
-> 建立 DO 有效电平
-> 再连接执行器业务
```

## CubeMX 配置要点

1. DO 配 GPIO_Input，按输出类型决定上拉/下拉
2. AO 配 ADC Analog
3. LED/蜂鸣器脚配 GPIO_Output 或 PWM
4. 先不用 EXTI，轮询验证有效电平

## 常用 HAL API

| API | 用途 |
|---|---|
| `HAL_GPIO_ReadPin` | 读取 DO |
| `HAL_ADC_Start/GetValue` | 读取 AO |
| `HAL_GPIO_WritePin` | 控制 LED/蜂鸣器 |
| `HAL_GetTick` | 非阻塞滤波/消抖 |

## Bring-up 顺序

1. 只验证供电、共地和静态电平。
2. 只验证 GPIO/总线和 HAL 返回值。
3. 读取 ID、DO、原始字节或原始 ADC 值。
4. 加入最少配置，保留每一步返回值。
5. 原始数据稳定后再换算、滤波和显示。
6. 最后加入业务状态机和异常恢复。

## 最小驱动框架

> 代码性质：示例框架，用于理解流程，不能保证直接编译。

```c
GPIO_PinState level = HAL_GPIO_ReadPin(SENSOR_DO_GPIO_Port, SENSOR_DO_Pin);
bool active = (level == sensor_active_level);
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, active ? LED_ON_LEVEL : LED_OFF_LEVEL);
```

## 调试方法

```text
供电/共地
-> 接线和电平
-> CubeMX 与 HAL 返回值
-> 原始波形/字节/数值
-> 模块状态
-> 换算或算法
-> 显示与业务
```

## 常见坑

| 现象 | 常见原因 | 处理方法 |
|---|---|---|
| DO 一直不变 | 阈值不合适/接错 AO | 观察模块指示灯并调阈值 |
| 逻辑相反 | 有效电平猜错 | 串口打印并实测 |
| AO 读数异常 | 未配 Analog/超范围 | 核对 ADC 引脚和电压 |
| 误触发 | 阈值附近抖动 | 加迟滞/连续采样确认 |
| 火焰测试危险 | 使用真实明火 | 仅做低风险教学测试 |
