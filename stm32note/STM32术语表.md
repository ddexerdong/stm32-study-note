# STM32 术语表

> 面向 STM32F103 / HAL / CubeMX 学习路径的高频术语速查。
>
> 目标不是替代数据手册和参考手册，而是快速判断一个词“属于哪类问题、该去哪个章节复习、工程上要注意什么”。

---

## 使用方法

- 先看术语所属类别，再回到对应章节复习。
- 这份表偏概念和工程理解，具体寄存器位以官方手册为准。
- 同名概念在不同 STM32 系列上可能有细节差异，本表默认 STM32F103C8T6。

## C 类型与数据宽度

这些类型都表示**无符号整数**，区别是占用的位数不同。嵌入式里优先使用这类固定宽度类型，因为它们在不同编译器和平台上含义更明确。

| 类型 | 位数 | 范围 | 常用场景 |
|------|------|------|----------|
| `uint8_t` | 8 位 | 0~255 | 字节、串口数据、数组缓冲区、DMA 字节流 |
| `uint16_t` | 16 位 | 0~65535 | ADC 值、16 位定时器计数值、16 位寄存器值 |
| `uint32_t` | 32 位 | 0~4294967295 | 系统时间、较大计数、定时器时间差、HAL API 参数 |

工程注意：

- `uint8_t` 常用于串口收发，因为串口一次传输的基本单位是 1 字节。
- `uint16_t` 能覆盖 STM32F103 的 12 位 ADC 值和多数 16 位定时器计数值。
- `uint32_t` 常用于 `HAL_GetTick()` 返回值和时间差计算，约 49.7 天后会溢出回 0。
- 计算时间差时建议使用 `HAL_GetTick() - start >= delay`，不要直接比较绝对时间点，这样能兼容 `uint32_t` 溢出。
