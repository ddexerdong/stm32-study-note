# STM32 术语表

> 这是一份给新手看的 STM32 常见概念词速查表。目标不是把寄存器手册背下来，而是先弄懂“这些词分别在控制什么”。
>
> 说明：同一个词在不同芯片系列里细节可能略有差异，这里优先按 STM32F103 / HAL / CubeMX 的学习路径来解释。

---

## 怎么查

- 看到不懂的词，先看它属于哪一类：硬件、时钟、中断、ADC、DMA、PWM、串口。
- 如果一个词后面标了“章节”，说明它在对应笔记里会反复出现。
- 这份表偏“概念解释”，不是寄存器手册；如果你要看具体参数，再去对应章节。

## 二、引脚与 GPIO 相关

| 术语 | 大白话解释 | 常见章节 |
|------|------------|---------|
| GPIO | 通用输入输出引脚，是 STM32 最基础的外设 | 02 |
| Pinout | 芯片引脚功能分配图 | 01 |
| Port | 一组 GPIO 口，比如 GPIOA、GPIOB | 02 |
| Pin | 端口里的某一根脚，比如 PB3 | 02 |
| 推挽输出 | 能主动输出高电平和低电平的输出方式 | 02 |
| 开漏输出 | 只能主动拉低，高电平要靠上拉 | 02 |
| 上拉输入 | 默认被拉到高电平，按下时再变低 | 02 |
| 下拉输入 | 默认被拉到低电平，按下时再变高 | 02 |
| 浮空输入 | 没有上拉/下拉，电平不稳定，慎用 | 02 |
| 模拟输入 | 关掉数字输入逻辑，给 ADC 用 | 05 |
| 复用推挽 | GPIO 交给外设使用，常用于 UART TX、PWM | 02, 04, 06 |
| 复用开漏 | GPIO 交给外设使用，常用于 I2C | 02 |
| 输出速度 | 控制信号翻转快慢，不是“数据速度” | 02 |
| 共地 | 所有模块地线接在一起，信号才有参考基准 | 02, 04 |
| 限流电阻 | 限制 LED 电流，防止烧坏引脚或 LED | 02 |
| 复用功能 | 一个引脚可以切换给不同外设使用 | 02, 04, 06 |
| 重映射 | 把外设功能换到另一组引脚上 | 04 |

## 三、时钟与定时器相关

| 术语 | 大白话解释 | 常见章节 |
|------|------------|---------|
| 时钟树 | 芯片内部时钟来源和分频关系图 | 01 |
| HSE | 外部高速晶振，一般板子上的 8MHz 晶振 | 01 |
| HSI | 芯片内部高速 RC 时钟 | 01 |
| PLL | 倍频器，把低频时钟放大到更高频率 | 01 |
| AHB | 高速总线，连着 CPU、Flash、RAM 等 | 01 |
| APB1 | 低速外设总线，常挂 TIM2/3/4、UART、I2C 等 | 03 |
| APB2 | 高速外设总线，常挂 TIM1、GPIO、ADC 等 | 03 |
| PCLK | APB 总线上的实际时钟频率 | 03 |
| TIMx_CLK | 定时器真正使用的时钟频率 | 03, 06 |
| 预分频 PSC | 把定时器时钟先降速 | 03, 06 |
| 自动重装载 ARR | 定时器计数上限，决定周期 | 03, 06 |
| 计数器 CNT | 定时器当前计数值 | 06 |
| 比较值 CCR | PWM 或输出比较里决定触发点的值 | 06 |
| Update Event | 定时器计数溢出后产生的更新事件 | 03, 07 |
| TRGO | 定时器的内部触发输出信号 | 07 |
| 计数溢出 | CNT 数到上限后回到 0 的动作 | 03, 07 |
| 基本定时器 | 只负责定时的最基础定时器 | 03 |
| 通用定时器 | 既能定时，也能做 PWM、输入捕获等 | 03, 06 |
| 高级定时器 | 功能更强，支持互补输出、死区、刹车 | 06 |
| PWM | 用固定频率方波的占空比控制输出效果 | 06 |
| 占空比 | 一个周期里高电平所占的比例 | 06 |
| 频率 | 每秒重复多少次周期信号 | 06 |
| 输出比较 | 定时器到达比较值时改变输出状态 | 06 |
| 输入捕获 | 记录外部信号边沿到来的时刻 | 06 |
| 互补输出 | 给电机驱动等功率电路用的一对反向输出 | 06 |
| 死区 | 互补输出切换时故意留出的空档时间 | 06 |
| 刹车输入 | 出现故障时强制关闭 PWM 输出 | 06 |

## 四、中断与事件相关

| 术语 | 大白话解释 | 常见章节 |
|------|------------|---------|
| 中断 | 硬件发信号，让 CPU 暂停当前任务先去处理紧急事 | 03 |
| 中断服务函数 | 真正处理某个中断的函数 | 03 |
| 回调函数 | HAL 在事件完成后自动调用的函数 | 03, 04, 05, 07 |
| NVIC | 中断控制器，负责管理中断优先级和响应 | 03 |
| 抢占优先级 | 决定能不能打断别的中断 | 03 |
| 响应优先级 | 同级中断同时到来时的排队顺序 | 03 |
| SysTick | 内核自带的系统定时器，HAL_Delay 靠它 | 03 |
| EXTI | 外部中断线，用引脚电平变化触发中断 | 03 |
| FLAG | 状态标志位，表示某个事件发生了 | 03, 04, 07 |
| volatile | 告诉编译器这个变量会被硬件/中断改动 | 03 |
| 阻塞 | 函数不返回，CPU 一直等 | 03, 04, 05 |
| 非阻塞 | 函数立即返回，后续靠中断或回调处理 | 03, 04, 05 |

## 五、串口相关

## 十一、看到这些词时怎么理解

| 词 | 先想什么 |
|----|---------|
| TRGO | “哪个定时器把信号发出去了？” |
| Update Event | “是不是定时器溢出了？” |
| Rank | “多通道采样时，这个数据排第几？” |
| Circular | “数组满了以后会不会继续从头写？” |
| NVIC | “这个中断是谁来管理优先级？” |
| EXTI | “是不是引脚电平变化触发了中断？” |
| PSC / ARR | “定时周期到底怎么分频和计数的？” |
| CCR | “PWM 高电平持续多久？” |
| IDLE | “串口这一帧是不是结束了？” |
| DMA | “数据是不是让硬件自动搬走了？” |
