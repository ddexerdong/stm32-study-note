# 17-18 定时器与中断

## 定时器工作原理

```
TIMx_CLK（来自APB）
    ↓ ÷ (PSC+1)     ← 预分频器
计数时钟
    ↓ 每个时钟CNT+1
CNT 计数器
    ↓ CNT == ARR 时溢出，产生中断
ARR 自动重载值
```

### 定时时间公式 ⭐

```
T = (PSC + 1) × (ARR + 1) / TIMx_CLK

例：TIM2时钟72MHz，定时1秒
PSC = 7199，ARR = 9999
T = (7199+1) × (9999+1) / 72,000,000 = 1s
```

## CubeMX配置步骤

1. Timers → TIM2 → Clock Source: Internal Clock
2. 填写 PSC 和 ARR
3. NVIC Settings → TIM2 global interrupt → Enable
4. 生成代码

## HAL 定时器启动

```c
// main函数中，在while(1)之前
HAL_TIM_Base_Start_IT(&htim2);  // 启动定时器中断
```

## 中断回调函数（最重要！）

```c
// 在 main.c 或 stm32f1xx_it.c 外部定义
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
    if (htim->Instance == TIM2) {
        // 每隔定时时间执行一次
        HAL_GPIO_TogglePin(GPIOB, GPIO_PIN_0);  // 翻转LED
    }
}
```

> ⚠️ 不要在这里写耗时操作（HAL_Delay等），中断要快进快出

## 中断优先级（NVIC）

```
优先级数字越小 = 优先级越高

抢占优先级（Preemption Priority）：
  → 高抢占优先级可以打断低抢占优先级的中断

响应优先级（Sub Priority）：
  → 同抢占优先级时，决定谁先执行（不能互相打断）
```

### 常用优先级设置

| 中断 | 抢占 | 响应 |
|------|------|------|
| SysTick（HAL_Delay用） | 15 | 0 |
| UART | 1 | 0 |
| TIM | 2 | 0 |
| EXTI按键 | 3 | 0 |

## 外部中断 EXTI（[18]）

### 触发方式

| 方式 | 场景 |
|------|------|
| 上升沿（Rising） | 按键松开时触发 |
| 下降沿（Falling） | 按键按下时触发 ⭐常用 |
| 双边沿（Both） | 任意变化 |

### 回调函数

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    if (GPIO_Pin == GPIO_PIN_0) {
        // 按键中断处理
        HAL_GPIO_TogglePin(GPIOB, GPIO_PIN_0);
    }
}
```

> ⚠️ 外部中断同样要加软件消抖！中断里用时间戳判断

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    if (GPIO_Pin == GPIO_PIN_0) {
        static uint32_t lastTime = 0;
        if (HAL_GetTick() - lastTime > 200) {  // 200ms防抖
            lastTime = HAL_GetTick();
            HAL_GPIO_TogglePin(GPIOB, GPIO_PIN_0);
        }
    }
}
```
