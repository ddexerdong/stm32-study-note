## [6] 核心板、面包板、扩展板介绍

### 知识点
- 核心板（最小系统板）：只含 STM32 芯片 + 晶振 + 复位电路 + 电源，所有 GPIO 通过排针引出
- 面包板：免焊接的电路实验板，上下横排是电源轨（+/-），中间竖排是信号插孔
- 扩展板：功能模块（传感器、电机驱动等）通过杜邦线连接到核心板

### 关键原理

**STM32F103C8T6 核心板关键引脚：**

| 功能 | 引脚 | 说明 |
|------|------|------|
| 电源 3.3V | 3V3 | 给 STM32 和低功耗外设供电 |
| 电源 5V | 5V | USB 输入，板载 LDO 降压到 3.3V |
| 地 | GND | 所有外设必须共地 |
| 串口烧录 | PA9(TX)、PA10(RX) | 通过 USB-TTL 模块烧录（非 ST-Link 方式） |
| SWD 调试 | SWDIO、SWCLK | ST-Link/DAP 调试烧录接口 |
| BOOT0 | BOOT0 | 启动模式选择（接地 = 从 Flash 启动） |
| 复位 | NRST | 低电平复位 |
| 板载 LED | PC13 | 大部分 C8T6 核心板板载 LED 接 PC13 |

### 面包板使用要点

```
面包板内部连接方式（俯视图）：
┌──────────────────────────────────┐
│ + ─────────────────────────── + │ ← 上电源轨（横向连通）
│ - ─────────────────────────── - │ ← 上地轨（横向连通）
├──────────────────────────────────┤
│ │ │ │ │ │ │ │ │ │ ... │ │ │ │ │ │ ← 信号插孔（纵向 5 孔连通，中间断开）
├──────────────────────────────────┤
│ + ─────────────────────────── + │ ← 下电源轨（横向连通）
│ - ─────────────────────────── - │ ← 下地轨（横向连通）
└──────────────────────────────────┘
```

### 易错点
- 杜邦线分公母，核心板用母对母，面包板用公对公
- 面包板中间有一条横向沟槽，**沟槽两侧的孔不连通**，插芯片要跨沟槽
- 杜邦线内部断裂外表看不出来，接触不良时优先换线排查

## [7-1] STM32、手册介绍

### 知识点
- STM32 命名规则解析
- 芯片选型方法
- 数据手册 vs 参考手册的区别

### 关键原理

#### 命名规则

```
STM32 F 103 C 8 T 6
 │     │  │  │ │ │ └─ 温度范围（6 = 工业级 -40~85℃）
 │     │  │  │ │ └─── 封装（T = LQFP）
 │     │  │  │ └───── Flash 大小（8 = 64KB, B = 128KB）
 │     │  │  └─────── 引脚数（C = 48pin, R = 64pin, V = 100pin）
 │     │  └────────── 子系列（103 = F1 基本型）
 │     └──────────── 系列（F = 通用, L = 低功耗, G = 主流）
 └────────────────── ST 产品线
```

本笔记默认使用 **STM32F103C8T6**（72MHz / 64KB Flash / 20KB RAM / 48pin）。

#### 两份手册的区别

| 手册类型 | 内容 | 什么时候看 |
|---------|------|----------|
| **数据手册（Datasheet）** | 电气特性、引脚定义表、封装尺寸 | 画原理图、选型、查引脚功能 |
| **参考手册（Reference Manual）** | 外设详细功能、寄存器描述 | 编程时查外设工作原理 |

> 💡 新手常犯的错误：下载了一本 1000+ 页的参考手册当数据手册看，找不到引脚定义。

### 易错点
- 买芯片/核心板时注意后缀：C8T6 和 CBT6 的 Flash 大小不同（64KB vs 128KB），程序可能放不下
- 查引脚功能用数据手册的 Pinouts 章节，不是参考手册

## [7-2] ARM、寄存器介绍

### 知识点
- ARM Cortex-M3 内核与 STM32 的关系
- 寄存器的概念
- 存储器映射

### 关键原理

```
ARM 公司  → 设计 Cortex-M3 内核（CPU 核心）
ST 公司   → 在 Cortex-M3 外面加上 Flash、RAM、GPIO、UART... = STM32
我们      → 通过操作外设寄存器来控制硬件
```

#### 寄存器是什么

寄存器就是芯片内部**有特殊功能的存储单元**，每个寄存器有一个固定地址。写不同的值到这个地址，硬件就有不同的行为。

```
例：GPIOB 的 ODR 寄存器（输出数据寄存器）
地址：0x40010C0C
写入 0x0001 → PB0 输出高电平，其余输出低电平
写入 0x0000 → 全部输出低电平
```

#### HAL 库替我们做了什么

```c
// 寄存器写法（你不需要这样写）：
*(volatile uint32_t *)0x40010C0C = 0x0001;  // PB0 拉高

// HAL 库写法（实际开发用这个）：
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);  // 一样的效果
```

> 💡 HAL 库就是帮我们操作寄存器的翻译官。你不需要背寄存器地址，但需要知道背后是寄存器在工作。

### 易错点
- HAL 库函数命名规则：`HAL_外设_操作()`，比如 `HAL_GPIO_WritePin`、`HAL_UART_Transmit`
- 寄存器是 volatile 的——值可能被硬件改变，编译器不能优化掉"看似重复"的读写

## [8] STM32CubeMX 新建 CubeIDE 工程

### 知识点
- CubeMX 图形化配置流程
- 时钟树配置
- 生成代码后的项目结构
- CubeIDE 编译烧录

### 关键原理

#### 工具链

| 工具 | 用途 |
|------|------|
| STM32CubeMX | 图形化配置引脚、时钟、外设 → 生成初始化代码 |
| STM32CubeIDE | 编写代码 + 编译 + 烧录 + 调试（内置 CubeMX） |

> 本笔记使用 **CubeIDE**（内含 CubeMX）。课程原版用的 MDK-Keil，底层 HAL 库是一样的，外设配置逻辑通用。

#### CubeMX 新建工程流程

1. **选芯片**：Commercial Part Number 输入 `STM32F103C8T6` → 双击选中
2. **配调试口**：System Core → SYS → Debug → **Serial Wire**（否则 SWD 口被禁用，烧不进去）
3. **配时钟树** ⭐：
   - HSE 选 `Crystal/Ceramic Resonator`
   - PLL Source Mux 选 HSE
   - PLL Mul 设为 `×9`
   - 确认 SYSCLK = 72MHz, APB1 ≤ 36MHz, APB2 ≤ 72MHz
4. **配外设**：按需配置 GPIO、UART、TIM 等
5. **生成代码**：Project Manager → Toolchain 选 STM32CubeIDE → 勾选 "Generate peripheral initialization as a pair of .c/.h files" → GENERATE CODE

#### 时钟树速查

```
HSE（8MHz 外部晶振）
  └→ PLL（×9）→ SYSCLK = 72MHz
                    ├→ AHB /1 → HCLK = 72MHz
                    ├→ APB1 /2 → PCLK1 = 36MHz（TIM2/3/4、UART2/3）
                    └→ APB2 /1 → PCLK2 = 72MHz（TIM1、UART1、ADC）
```

> ⚠️ **定时器时钟坑**：APB1 分频 ≠ 1 时，定时器时钟 = PCLK1 × 2 = **72MHz**（不是 36MHz）

#### 🔴 最重要的规则：用户代码保护区

CubeMX 重新生成代码时，只有下面这对注释之间的代码保留：

```c
/* USER CODE BEGIN xxx */
// ✅ 你的代码写这里
/* USER CODE END xxx */
```

写在注释外面的代码，重新生成后全部丢失。

#### 项目结构

```
项目/
├── Core/
│   ├── Inc/main.h        ← 全局声明
│   └── Src/main.c        ← ⭐ 用户代码主战场
├── Drivers/              ← HAL 库，不要改
└── project.ioc           ← CubeMX 配置文件
```

### CubeMX 配置步骤

1. 打开 CubeIDE → File → New → STM32 Project
2. 选芯片 STM32F103C8T6
3. SYS → Debug → Serial Wire
4. Clock Configuration → 配时钟树（HSE → PLL ×9 → 72MHz）
5. Pinout → 点 PC13 → GPIO_Output
6. Project Manager → 填工程名 → 选 CubeIDE → 生成
7. 打开生成的工程，在 main.c 的 while(1) 中添加点灯代码
8. 点 🔨 Build → 点 ▶️ Run 烧录

### HAL 库代码模板

```c
// 板载 LED 闪烁验证（main.c 的 while(1) 中）
while (1)
{
    HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);  // 翻转 PC13（板载 LED）
    HAL_Delay(500);                            // 延时 500ms
}
```

### 易错点
- Debug 口没配 Serial Wire → 烧录不进去
- BOOT0 没接地 → 烧录后程序不跑
- CubeMX 重新生成 → 写在 USER CODE 之外的代码全丢
- 安装路径有中文 → 编译报错
