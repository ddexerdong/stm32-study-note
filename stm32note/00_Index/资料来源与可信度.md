# 资料来源与可信度

## 来源层级

| 来源 | 适合确认 | 不宜单独确认 |
|---|---|---|
| 芯片数据手册 / 参考手册 | 引脚、电气限制、时钟、寄存器、外设机制 | 课程模块接线和封装 |
| HAL/LL 官方文档 | API 参数、状态、回调和驱动行为 | 第三方模块算法 |
| 野火官方 PDF | F103/HAL 外设原理和同类实验 | 未设专题的模块细节 |
| 视频课程 | 课程板接线、CubeMX 参数、演示流程 | 可能随版本变化的通用结论 |
| 模块手册 / 官方库 | 地址、寄存器、时序、公式和库接口 | 未核对的课程封装 |
| 现有笔记 / 实测 | 已跑通工程和个人踩坑 | 尚未复现的硬件参数 |
| 网络资料 | 仅限厂商官网、官方示例和来源明确的仓库，用于交叉检索 | 不能凭单篇博客或未知代码确认参数 |

## Frontmatter 来源标识

| 标识 | 含义 | 可支持的结论 |
|---|---|---|
| `local-notes` | 重构前课程笔记、术语表、踩坑记录和本仓库审计报告 | 学习路径、已记录实验流程、个人理解和历史踩坑 |
| `st-reference-manual` | STM32F103 参考手册 | 外设机制、寄存器行为、时钟和中断关系 |
| `st-datasheet` | 具体 STM32F103 型号数据手册 | 引脚、电气限制、封装和存储资源 |
| `st-hal-documentation` | ST HAL 驱动文档和官方示例 | HAL API 参数、状态、启动与回调关系 |
| `module-datasheet` | 器件厂商数据手册或官方协议文档 | 模块地址、寄存器、时序、公式和限制 |

Frontmatter 只说明某文件整理时使用过哪类资料，不等于文件内所有板级参数都已实测。

## 笔记标记

- `PDF 强对应`：可作为原理和 HAL 主线的重要依据。
- `PDF 弱对应`：只能支撑底层外设，不能替代模块资料。
- `视频待核对`：课程细节尚未验证。
- `模块资料待核对`：寄存器、算法、公式或库接口待查。

## 使用原则

1. 先区分“芯片外设知识”和“模块案例参数”。
2. 参数写成确定事实前，至少有手册、视频或实测证据。
3. 引脚、地址、波特率、PWM/CAN 参数以实际开发板原理图和 CubeMX 配置为准。
4. 未确认内容统一登记到 [[视频实测核对表]]。

## 从资料到结论的最小证据链

```text
芯片/模块型号确认
  -> 找到对应版本的官方手册
  -> 核对原理图和 CubeMX 配置
  -> 用 HAL 返回值、串口日志或逻辑分析仪验证
  -> 再把参数写成确定事实
```

课程视频能证明课程当时的接线与流程，但版本可能变化；官方手册能证明器件行为，但不能自动证明当前模块板的焊接、地址脚或外围电路。

## 官方资料入口

- STM32F103 数据手册、参考手册和应用资料：[ST STM32F103 documentation](https://www.st.com/en/microcontrollers-microprocessors/stm32f103/documentation.html)
- STM32F1 HAL 驱动源码与 API 注释：[STMicroelectronics/stm32f1xx-hal-driver](https://github.com/STMicroelectronics/stm32f1xx-hal-driver)
- MAX30102 数据手册：[Analog Devices MAX30102](https://www.analog.com/en/products/max30102.html)
- MPU-6050 寄存器说明：[TDK MPU-6000/MPU-6050 Register Map](https://www.invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Register-Map1.pdf)
- VL53L0X 产品资料与 API：[ST VL53L0X](https://www.st.com/en/imaging-and-photonics-solutions/vl53l0x.html)
- BMP280 数据手册：[Bosch Sensortec BMP280](https://www.bosch-sensortec.com/products/environmental-sensors/pressure-sensors/bmp280/)
- ESP8266 AT 指令：[Espressif ESP-AT Command Set](https://docs.espressif.com/projects/esp-at/en/release-v2.1.0.0_esp8266/AT_Command_Set/index.html)

具体器件版本、模块板原理图和课程源码仍需单独绑定；入口链接只用于定位官方资料，不代表当前硬件已经实测。
