## 建议使用方式

1. 按 [[STM32学习路线]] 完成当前阶段的最小实验。
2. 用 [[HAL_API速查表]] 找 API 家族，再回到正文理解启动函数与回调关系。
3. 参数不确定时先查 [[资料来源与可信度]]，不要直接复制模块代码。
4. 实验失败时按 [[通用调试方法]] 收集证据，并把复现过程写入 [[踩坑日记]]。
5. 视频或实测确认后，更新 [[视频实测核对表]]，同时清理正文中的待核对项。

## 内容边界

- Core / Peripherals / Communication 说明 STM32F103 和 HAL 的通用机制。
- Modules 说明第三方器件的连接、数据流和 bring-up 方法；未确认参数不会写成确定事实。
- Projects 关注跨外设协作、状态机、缓冲区和故障恢复，不替代模块数据手册。
- Archive 保留原课程语境，不作为当前主线继续扩写。
