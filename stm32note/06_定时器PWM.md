## 知识地图

| 新名词 | 解释 | 哪里出现 |
|--------|------|---------|
| PWM | Pulse Width Modulation，脉冲宽度调制。固定频率，改变高电平占比来控制输出效果 | [23-1] |
| 占空比 | 高电平时间 / 周期 × 100%。0% = 一直低，50% = 半高半低，100% = 一直高 | [23-1] |
| CCR (Capture/Compare Register) | 比较寄存器。CNT < CCR 时输出高电平（Mode 1），≥ CCR 时输出低电平 | [23-1] |
| 输出比较 | 定时器的输出功能之一，CNT 和 CCR 比较后改变引脚电平。PWM 是输出比较的特例 | [23-1] |
| 互补输出 | 高级定时器特性：同一通道输出两路反向的 PWM 信号（CHx 和 CHxN） | [22-2] |
| 死区时间 | 互补输出时，两路信号切换之间的"同时关断"时间，防止上下管导通短路 | [22-2] |
| 刹车输入 | 高级定时器紧急停止引脚，收到信号后强制关闭所有 PWM 输出 | [22-2] |
| 舵机 | 一种位置伺服电机，通过 PWM 脉宽控制输出角度。标准信号 50Hz，0.5~2.5ms 脉宽 | [23-1] |

## TIM PWM HAL 函数族总览

| 函数 | 作用 |
|------|------|
| `HAL_TIM_PWM_Start(&htim, Channel)` | 启动 PWM 输出（无中断） |
| `HAL_TIM_PWM_Stop(&htim, Channel)` | 停止 PWM 输出 |
| `HAL_TIM_PWM_Start_IT(&htim, Channel)` | 启动 PWM + 中断（每个 PWM 周期结束时回调） |
| `HAL_TIM_PWM_Stop_IT(&htim, Channel)` | 停止 PWM 中断 |
| `__HAL_TIM_SET_COMPARE(&htim, Channel, Value)` | 动态修改 CCR（宏，直接写寄存器） |
| `__HAL_TIM_GET_COMPARE(&htim, Channel)` | 读取当前 CCR 值（宏） |
| `HAL_TIM_PWM_PulseFinishedCallback(htim)` | PWM 脉冲完成回调（需要开中断） |

## [22-1] 通用定时器基础中断（重温）

本节和 [03](03_中断与定时器.md) [17] 重复，此处只补充通用定时器能做而 SysTick 做不了的事：

| 功能 | SysTick | 通用定时器 TIM2/3/4 |
|------|---------|-------------------|
| 定时中断 | ✅（1ms 固定） | ✅（任意周期） |
| PWM 输出 | ❌ | ✅ |
| 输入捕获（测脉宽） | ❌ | ✅ |
| 输出比较 | ❌ | ✅ |
| 编码器模式 | ❌ | ✅ |
| 定时精度 | 24 位 | 16 位 |
| TRGO 信号 | ❌ | ✅（Update Event） |

通用定时器 16 位，PSC 和 ARR 各最大 65535。大部分定时任务（1ms 到几十秒）16 位足够。如果单次计时不够，可以通过软件级联。

### 通用定时器清单

| 定时器 | 总线 | 时钟 | 通道 |
|--------|------|------|------|
| TIM1 | APB2 | 72MHz | 4 + 3 互补（高级） |
| TIM2 | APB1 | 72MHz | 4 |
| TIM3 | APB1 | 72MHz | 4 |
| TIM4 | APB1 | 72MHz | 4 |

## [22-2] 高级定时器 TIM1/8

### 和通用定时器的结构差异

```
通用定时器 (TIM2~4):
  ┌──────┐
  │ CNT  │──→ 溢出/比较 → 4 通道输出
  │ PSC  │    (CH1, CH2, CH3, CH4)
  │ ARR  │
  └──────┘

高级定时器 (TIM1/8):
  ┌──────┐
  │ CNT  │──→ 溢出/比较 → 4 通道 + 3 互补 (CH1+CH1N, CH2+CH2N, CH3+CH3N)
  │ PSC  │──→ 死区发生器 (插入上下管同时关断时间)
  │ ARR  │──→ 刹车电路 (紧急关断所有输出)
  │ RCR  │──→ 重复计数器 (每 N 次溢出才产生一次 Update Event)
  └──────┘
```

### 互补输出与死区

半桥/全桥电机驱动电路中，上下两个 MOS 管如果同时导通，会直接短路烧毁。互补输出保证同通道的主输出（CHx）和互补输出（CHxN）始终反相。

死区时间 = 切换时上下管都关闭的时间窗口，由 DTG（Dead-Time Generator）寄存器配置：

```
CHx:  ────┐         └───────
CHxN:      └───────┐
          ←死区→   ←死区→
          （两路都关）
```

### 刹车输入

BREAK 引脚收到有效电平 → 硬件立即强制所有 PWM 输出进入预设的安全状态（高阻或强制低）。响应时间在纳秒级，软件来不及反应。

### 易错点
- 只做定时中断或基础 PWM 时，高级定时器和通用定时器用法完全一样。互补、死区、刹车只在电机驱动场景用到
- TIM1 在 APB2 上（72MHz），TIM2 在 APB1 但时钟也是 72MHz（注意 APB1 预分频）

## [23-1] PWM 控制舵机

### PWM 产生的硬件逻辑

定时器工作在 PWM 模式下，CNT、CCR 和输出引脚之间的关系（以 PWM Mode 1 为例）：

```
CNT:  0 ────→ CCR ────→ ARR → 0 ────→ CCR ────→ ARR → 0...
             ↑                  ↑
输出引脚：  高电平             低电平

CNT < CCR  → 输出高电平
CNT ≥ CCR  → 输出低电平
```

Mode 2 电平反相（CNT < CCR 输出低电平），其他相同。

### 四个寄存器在 PWM 场景的具体角色

| 寄存器 | 决定什么 | 可动态修改？ |
|--------|---------|------------|
| PSC | 计数频率。和 ARR 一起决定 PWM 频率 | 否（需停止重配） |
| ARR | 周期。和 PSC 一起决定 PWM 频率 | 否（需停止重配） |
| CNT | 内部运行计数器，只读 | 只读 |
| CCR | 高电平时长。在 PSC/ARR 固定时决定占空比 | **是**（`__HAL_TIM_SET_COMPARE` 动态修改） |

所以运行时调整占空比只需改 CCR，频率保持不变。

### PWM 频率/占空比公式推导

```
已知：TIMx_CLK（定时器时钟）、PSC、ARR、CCR

1. 计数频率 = TIMx_CLK / (PSC + 1)
   解释：PSC 把定时器时钟 N 分频。PSC=0 不分频；PSC=71 分频 1/72

2. 每次计数时间 = (PSC + 1) / TIMx_CLK
   一个计数周期的时间

3. PWM 周期 = (ARR + 1) × 每次计数时间
           = (ARR + 1) × (PSC + 1) / TIMx_CLK

4. PWM 频率 = 1 / 周期 = TIMx_CLK / [(PSC + 1) × (ARR + 1)]

5. 高电平时间 = CCR × 每次计数时间 = CCR × (PSC + 1) / TIMx_CLK

6. 占空比 = 高电平时间 / 周期 = CCR / (ARR + 1) × 100%
```

### PWM 模式 1 vs 模式 2

| 模式 | CNT < CCR 时输出 | CNT ≥ CCR 时输出 | 使用频率 |
|------|-----------------|-----------------|---------|
| PWM Mode 1 | 高电平 | 低电平 | 99% 场景 |
| PWM Mode 2 | 低电平 | 高电平 | 特殊需求 |

两种模式只是电平反相，数学关系完全相同。

### 舵机控制协议

常见的舵机使用 50Hz PWM 信号（周期 = 20ms）。角度由高电平持续时间（脉宽）决定，范围通常 1ms~2ms（约 90° 范围），部分可扩展。具体以舵机手册为准。

```
50Hz PWM 控制舵机（TIMx_CLK = 72MHz, PSC=71, ARR=19999）:

脉宽        CCR (理论)   角度（参考）
0.5ms    →    500    →    -90°
1.0ms    →   1000    →    -45°
1.5ms    →   1500    →      0° (中点)
2.0ms    →   2000    →    +45°
2.5ms    →   2500    →    +90°
```

计算验证：PSC=71, ARR=19999 → 频率 = 72M / (72 × 20000) = 50Hz ✓
CCR=1500 → 占空比 = 1500/20000 = 7.5% → 7.5% × 20ms = 1.5ms ✓

> ⚠️ 不同品牌舵机的极限参数不同，先用 1000~2000 范围测试，确认电机能自由运转再慢慢扩大。

### `__HAL_TIM_SET_COMPARE` 详解

```c
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 1500);
```

这是一个**宏**（不是函数调用），展开后直接写定时器的 CCR 寄存器。所以执行速度极快（单条汇编指令）。

三个参数：
- `&htim3`：定时器句柄指针
- `TIM_CHANNEL_1`：通道号（1~4）。每个通道有独立的 CCR 寄存器
- `1500`：目标 CCR 值。必须 ≤ ARR，否则占空比异常

> 对应的读取宏：`__HAL_TIM_GET_COMPARE(&htim3, TIM_CHANNEL_1)` 返回当前 CCR 值。

### CubeMX 配置

1. Timers → TIM3 → Channel1: **PWM Generation CH1**
2. Prescaler 和 Counter Period 按频率公式填入
3. Pulse = 初始 CCR（启动时的占空比，填 0 或中间值均可）
4. GPIO 会自动切到复用推挽输出。核对引脚映射：TIM3_CH1 通常对应 PA6，但不同芯片可能不同

### 代码

```c
// 启动舵机
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

// 设置角度
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 1500);  // 0° (中点)
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 1000);  // -45°
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 2000);  // +45°

// 停止
HAL_TIM_PWM_Stop(&htim3, TIM_CHANNEL_1);
```

### 舵机供电警告

**绝不能从 ST-Link 的 3.3V 给舵机供电。** 舵机工作电流（几百 mA 到 1A+）远超 ST-Link 3.3V 的输出能力。必须外接独立电源（如 5V 或舵机额定电压），并和 STM32 共地。

### 易错点
- PWM 引脚无输出 → 忘了调 `HAL_TIM_PWM_Start` / 通道和引脚不匹配
- 舵机不转或抖动 → **供电不足**（从 ST-Link 3.3V 取电最典型）
- 占空比异常 → CCR 超出 ARR
- 舵机控制的是脉宽（μs），不是占空比百分比

## [23-2] PWM 实现呼吸灯

### LED 调光原理

LED 的亮度正比于流过它的平均电流。PWM 调光利用了人眼的视觉暂留效应：

- 频率 > 50Hz → 人眼感觉不到闪烁，感知为连续光
- PWM 频率固定，占空比越大 → 平均电流越大 → 人眼感知越亮
- 所以调整占空比 = 调整亮度

```
0% 占空比    → 一直灭
25% 占空比   → 微亮
50% 占空比   → 半亮
100% 占空比  → 全亮
```

### 代码

```c
// 呼吸灯（教学写法：动态改 CCR，会阻塞 CPU）
while (1)
{
    // 渐亮：CCR 从 0 平滑增大到 ARR
    for (uint16_t duty = 0; duty <= 1000; duty++)
    {
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
        HAL_Delay(1);
    }
    // 渐灭
    for (uint16_t duty = 1000; duty > 0; duty--)
    {
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, duty);
        HAL_Delay(1);
    }
}
```

这个写法的问题：`HAL_Delay(1)` 阻塞 1ms，渐亮 + 渐灭共 2000 次循环 = CPU 阻塞约 2 秒。更好的方法：在定时器中断里实现呼吸灯状态机，CPU 解放出来处理其他任务。

### PWM 频率选择

| 场景 | 推荐频率 | 原因 |
|------|---------|------|
| LED 调光 | 1kHz 以上 | 高于人眼闪烁感知（50Hz），留 20 倍余量 |
| 舵机 | 50Hz | 舵机标准协议 |
| 直流电机驱动 | 10~20kHz | ① 避开人耳听觉范围（<20kHz 会听到啸叫）② 电机线圈电感适合 |
| 无源蜂鸣器 | 1~5kHz | 人耳最敏感频段，频率决定音调 |

### 易错点
- `__HAL_TIM_SET_COMPARE` 是宏不是函数，不可取地址，不要在回调里传函数指针
- 呼吸灯用 `HAL_Delay` 导致 CPU 长时间阻塞，只是教学写法
- 呼吸灯闪烁（不流畅） → PWM 频率太低，提高到 1kHz 以上
- CCR 值超过 ARR → 输出异常（始终高或始终低）
