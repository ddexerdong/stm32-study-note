## 关键公式速查

```
定时时间：T = (PSC+1)(ARR+1) / TIMx_CLK
ADC电压： V = ADC值 / 4095 × 3.3
PWM频率： f = TIMx_CLK / [(PSC+1)(ARR+1)]
PWM占空比：D = CCR / (ARR+1) × 100%
```
