# 踩坑日记

> 实验过程中遇到的问题和解决方法，按时间倒序记录。
>
> 目标：把“现象 -> 原因 -> 解决 -> 复盘”沉淀成可复用的工程经验。

---

## 记录模板

```text
日期：
章节：
实验：
现象：
原因：
解决：
复盘：
```

建议原则：

- 先写现象，不要一上来猜原因。
- 记录关键参数，例如波特率、PSC/ARR、引脚号、供电电压。
- 解决后补一句复盘，方便以后面试或复习时回忆。

---

## 总体排查顺序

```text
供电
-> 共地
-> 接线
-> CubeMX 配置
-> 初始化函数是否调用
-> HAL API 是否启动
-> 中断 / DMA / 回调是否进入
-> 业务逻辑
```

大多数入门问题不是算法错，而是电源、地线、引脚、模式、启动顺序错。

## 各章节经典坑速查

### [[01_准备与基础认知|01 准备与基础认知]]

| 坑 | 原因 | 解决 |
|----|------|------|
| 烧录不进去 | `SYS -> Debug` 没配 `Serial Wire` | CubeMX 中打开 SWD |
| 烧录后程序不跑 | `BOOT0` 悬空或被拉高 | 正常运行时 `BOOT0` 下拉到 GND |
| 代码重新生成后丢失 | 写在 `USER CODE` 区域外 | 所有用户代码放入 `USER CODE BEGIN/END` |
| 定时器时间算不对 | 不知道真实 `TIMx_CLK` | 查 APB 分频和定时器 x2 规则 |
| 编译/路径异常 | 工具链或工程路径含中文、特殊字符 | 新手阶段使用纯英文路径 |

### [[02_GPIO与传感器|02 GPIO 与传感器]]

| 坑 | 原因 | 解决 |
|----|------|------|
| LED 不亮 | GPIO 模式、极性或限流电阻问题 | 先用万用表量 GPIO 电压 |
| LED/GPIO 烧坏 | LED 没串限流电阻 | 串 220 ohm~1 k ohm |
| 三个流水灯顺序不对 | 三路 GPIO 宏名、接线或有效电平对不上 | 先单独点亮每个 LED，再按顺序组合 |
| 按键按一下触发多次 | 机械抖动 | 加 20 ms 延时或状态机消抖 |
| 按键控制 LED 抖动 | 松手等待或边沿确认不完整 | 消抖后等待按键释放，或改状态机 |
| 按键状态一直不变 | 上拉/下拉和接线不匹配 | 上拉输入配按键接 GND |
| 蜂鸣器不响 | 有源/无源类型搞错或驱动不足 | 有源给电平，无源给 PWM，并加三极管 |
| GPIO 烧坏 | 蜂鸣器/继电器直接接 GPIO | 用三极管、MOS 或驱动芯片 |
| 传感器不触发 | 没共地、阈值没调、电平判断反了 | 量 DO 电压，调电位器，确认有效电平 |
| LM393 模块有效电平判断反 | DO 高低电平含义和模块指示灯理解错 | 串口打印 DO，再决定是否取反 |

### [[03_中断与定时器|03 中断与定时器]]

| 坑 | 原因 | 解决 |
|----|------|------|
| 定时器回调不触发 | 调了 `_Start` 而不是 `_Start_IT` | 使用 `HAL_TIM_Base_Start_IT` |
| 中断没进 | NVIC 没使能 | CubeMX 勾选对应中断 |
| 程序卡死在中断里 | 中断里调用 `HAL_Delay()` | 中断只设标志位，主循环处理 |
| 标志位主循环读不到 | 没加 `volatile` | 共享变量声明为 `volatile` |
| 定时时间不准 | 忽略 APB 定时器 x2 规则 | 重新计算 `TIMx_CLK` |
| EXTI PA0/PB0 冲突 | 同一 EXTI 线只能选一个端口 | 换不同编号引脚 |
| 按键 EXTI 触发多次 | 机械抖动边沿多次触发 | 时间戳消抖 |

### [[04_串口与DMA|04 串口与 DMA]]

| 坑 | 原因 | 解决 |
|----|------|------|
| 串口不通 | TX/RX 同名相接 | 交叉连接：TX -> RX，RX -> TX |
| 收到乱码 | 波特率不一致、未共地、5 V 电平 | 核对 115200/8N1、共地、3.3 V |
| `printf` 没输出 | 没重定向底层输出函数 | 实现 `__io_putchar` 或 `fputc` |
| `%f` 不显示 | 未开启浮点打印 | 链接选项添加 `-u _printf_float` |
| 中断接收只触发一次 | 回调里忘记重启接收 | 回调末尾重新 `HAL_UART_Receive_IT` |
| 定长接收一直不回调 | 没收到指定长度 | 改单字节命令或 IDLE + DMA |
| IDLE 不触发 | 没使能 `UART_IT_IDLE` | 调用 `__HAL_UART_ENABLE_IT` |
| DMA 后续不收 | 没重启 DMA | 处理完后重新 `HAL_UART_Receive_DMA` |
| 串口重映射后不通 | CubeMX 引脚改了，实际接线还在旧脚组 | 同步检查 AFIO、GPIO 复用和 USB-TTL 接线 |
| 多串口回调没区分来源 | 所有串口共用一个回调函数 | 用 `huart->Instance` 或句柄判断来源 |
| DMA buffer 异常 | 接收缓冲区定义成局部变量或被覆盖 | DMA buffer 用全局或静态变量保存 |
| 跨文件变量报错 | `it.c` 使用 `main.c` 变量未声明 | 在 `it.c` 中 `extern` |
| 中断里卡顿 | IRQ 中大量 `printf` 或发送 | 中断置标志，主循环处理 |

### [[05_ADC模数转换|05 ADC 模数转换]]

| 坑 | 原因 | 解决 |
|----|------|------|
| ADC 值一直为 0 | 引脚没配 ADC、没启动、外部电压为 0 | 查 CubeMX、接线和启动函数 |
| 读数固定偏移 | 忘记校准 | 上电调用 `HAL_ADCEx_Calibration_Start` |
| 多通道数据错位 | Rank 和数组索引没对应 | 明确 `adcBuf[0]=Rank1` |
| 多通道只读最后一个 | 轮询读 DR 被覆盖 | 多通道使用 DMA |
| DMA 一轮就停 | Continuous 或 DMA Continuous Requests 没开 | CubeMX 打开对应选项 |
| ADC + DMA 没数据 | 没调用 `HAL_ADC_Start_DMA` 或 DMA 未绑定 ADC | 检查 CubeMX DMA、启动函数和 HAL 返回值 |
| ADC + DMA 长度错误 | DMA 长度和 Rank 数量不一致 | 长度按通道数量填写，并建立 Rank 对照表 |
| 数据抖动大 | 采样时间短、电源噪声、源阻抗高 | 增大采样时间、加滤波、做平均 |
| 输入损坏风险 | ADC 引脚电压超过 3.3 V | 分压或限幅后再输入 |
| MQ 传感器前几分钟不准 | 传感器未预热 | 上电等待 2 分钟以上 |

### [[06_定时器PWM|06 定时器 PWM]]

| 坑 | 原因 | 解决 |
|----|------|------|
| PWM 无输出 | 忘记 `HAL_TIM_PWM_Start` | 初始化后显式启动 PWM |
| PWM 无输出 | 通道和引脚不匹配 | 查 CubeMX Pinout 和数据手册 |
| 占空比异常 | CCR 超过 ARR | 限制 CCR 范围 |
| 舵机不转/抖动 | 供电不足或未共地 | 外接舵机电源并共地 |
| 舵机角度不准 | 脉宽范围和舵机型号不匹配 | 查手册或实测标定 |
| 呼吸灯闪烁 | PWM 频率太低 | 提高到 1 kHz 以上 |
| CPU 被阻塞 | 用 `HAL_Delay` 做长渐变 | 改状态机或定时器节拍 |

### [[07_TIM触发ADC采集|07 TIM 触发 ADC]]

| 坑 | 原因 | 解决 |
|----|------|------|
| ADC 不触发 | TIM 没配 TRGO | `Trigger Output` 选 `Update Event` |
| ADC 不触发 | ADC 外部触发源选错 | 选对应 `Timer X Trigger Out` |
| 程序卡在 Poll | TIM 没启动或触发链路断 | 检查 TIM Start、TRGO、ADC Trigger |
| 采样节奏异常 | Continuous 和外部触发混用 | TIM 触发模式下关闭 Continuous |
| 前几次数据异常 | TIM 早于 ADC 启动 | 先 ADC Start，再 TIM Start |
| 温度比室温高 | 测的是芯片硅片温度 | 只当芯片内部温度参考 |
| `%f` 不输出 | 未启用浮点打印 | 添加 `-u _printf_float` |

### [[08_TIM通道捕获|08 TIM 通道捕获]]

| 坑 | 原因 | 解决 |
|----|------|------|
| 编码器读数一直为 0 | 没调用 `HAL_TIM_Encoder_Start` | 初始化后启动编码器模式 |
| 编码器方向反了 | A/B 相接反或极性不匹配 | 交换 A/B 相或调整 IC 极性 |
| 编码器数值跳动 | 信号抖动或接线不稳 | 增加 IC Filter，检查接线 |
| 输入捕获无回调 | 没调用 `HAL_TIM_IC_Start_IT` 或 NVIC 未开 | 启动输入捕获中断，勾选 NVIC |
| 超声波距离明显不对 | TIM 计数频率不是 1 MHz | 检查 `TIMx_CLK` 和 Prescaler |
| 程序卡死等 ECHO | 没有超时保护 | 用 `HAL_GetTick()` 加超时 |
| ECHO 输入风险 | HC-SR04 输出 5 V | 使用分压或电平转换 |
| `%f` 不输出 | 未启用浮点打印 | 添加 `-u _printf_float` |

### [[00_课程环境与工具链|00 课程环境与工具链]]

| 坑 | 原因 | 解决 |
|----|------|------|
| DAP / ST-LINK 识别不到 | 驱动未安装或 USB 线只支持充电 | 安装驱动，换数据线和 USB 口 |
| MDK 找不到芯片型号 | Pack / 芯片包缺失 | 安装对应 STM32F1 芯片包 |
| 下载后不能调试 | `SYS -> Debug` 没选 `Serial Wire` | CubeMX 中打开 Serial Wire |
| 串口下载失败 | BOOT0 状态或串口接线不对 | 核对 BOOT0、TX/RX 交叉和复位步骤 |
| 重新生成工程后代码丢失 | 代码写在 USER CODE 区域外 | 用户代码只写在 USER CODE BEGIN/END 内 |
| 编译路径异常 | 工程路径有特殊字符或工具链路径错误 | 新手阶段使用稳定英文路径并检查 MDK 配置 |

### [[09_电机与工程模板|09 电机与工程模板]]

| 坑 | 原因 | 解决 |
|----|------|------|
| 电机不转 | STBY 未使能、方向脚没配或电机供电缺失 | 先查 STBY、AIN/BIN、VM 和 PWM |
| 电机只响不转 | 供电电流不足或机械负载太大 | 换足够电流电源，空载测试 |
| PWM 有波形但电机不动 | 驱动模块未使能或 VM/VCC 混淆 | 区分逻辑电源 VCC 和电机电源 VM |
| 一接电机 MCU 复位 | 电机电流冲击或没有共地/电源隔离差 | 电机单独供电并共地，加滤波 |
| 方向控制反了 | AIN1/AIN2 或电机线接反 | 交换方向逻辑或电机线 |
| GPIO 直接驱动电机 | GPIO 电流能力不足且有反灌风险 | 必须使用电机驱动芯片或功率器件 |
| 工程模板文件找不到头文件 | BSP 路径没加入 Include Path | 在 MDK 中添加 BSP include 路径 |

### [[10_DWT与单总线传感器|10 DWT 与单总线传感器]]

| 坑 | 原因 | 解决 |
|----|------|------|
| DWT 计数一直为 0 | CYCCNT 未开启 | 初始化 DWT 并使能周期计数 |
| DWT 初始化无效 | Debug 相关寄存器未使能 | 按课程封装打开调试计数功能 |
| 微秒延时不准 | SystemCoreClock 不对或被中断打断 | 核对系统时钟，关键时序减少中断干扰 |
| DHT11 无响应 | 起始信号时序或 GPIO 模式错误 | 按时序切换输出/输入并核对延时 |
| DHT11 校验失败 | 数据线抖动、时序窗口不准或读取位错误 | 先打印原始 5 字节，再查校验和 |
| DHT11 数据线无上拉 | 单总线空闲电平不稳定 | 加上拉电阻或按模块原理图确认上拉 |
| 数据线一直高 | 没有上拉或输入模式配置错误 | 检查上拉电阻和 GPIO 模式 |
| 读数偶尔失败 | DHT11 采样间隔太短 | 按模块要求留足读取间隔 |

### [[11_I2C与OLED|11 I2C 与 OLED]]

| 坑 | 原因 | 解决 |
|----|------|------|
| I2C 扫不到地址 | 没供电、没共地、SCL/SDA 接反或无上拉 | 按供电、共地、接线、上拉顺序查 |
| OLED 不亮 | 地址、初始化命令或供电不对 | 先扫地址，再核对初始化序列 |
| 地址左移混淆 | HAL 常用 8 位地址形式 | 统一在驱动里处理地址左移 |
| OLED 控制字节错误 | 命令和数据没有区分，或连续写格式不对 | 按视频/模块资料确认写命令和写数据封装 |
| HAL I2C 返回超时 | 总线被拉低或外设无 ACK | 检查 SDA/SCL 电平和上拉 |
| 显示乱码 | 字库、取模方向或页地址不匹配 | 核对字库格式和 OLED 控制器 |
| 只显示一部分 | 坐标、页数或列数写错 | 用清屏和单字符定位测试 |
| 接多个 I2C 模块冲突 | 地址相同或上拉过强/过弱 | 分开测试地址和总线波形 |

### [[12_I2C传感器|12 I2C 传感器]]

| 坑 | 原因 | 解决 |
|----|------|------|
| WHO_AM_I 读不对 | 地址、寄存器或读写流程错误 | 先用地址扫描和单寄存器读取验证 |
| 传感器地址错误 | 7 位地址和 HAL 左移地址混用 | 在驱动宏里统一写法 |
| 连续读长度错误 | 数据寄存器数量或起始地址不对 | 按手册/课程确认长度后再拼值 |
| 原始值高低字节反了 | 多字节数据拼接顺序错误 | 打印每个字节，再组合成原始值 |
| 数据一直不变 | 未配置工作模式或未等待数据就绪 | 写配置后读状态寄存器 |
| 公式换算结果离谱 | 量程、校准参数或单位换算错 | 先保留原始值，再逐步套公式 |
| 算法前就崩溃 | 底层通信未通却直接跑上层算法 | 先读 ID 和原始数据 |

### [[13_SPI与存储器传感器|13 SPI 与存储器传感器]]

| 坑 | 原因 | 解决 |
|----|------|------|
| SPI 读 ID 失败 | SCK/MOSI/MISO/CS 接线或模式错误 | 查接线、CS 和 CPOL/CPHA |
| 读回全 0xFF | CS 未拉低、MISO 悬空或芯片无响应 | 用逻辑分析仪看 CS 和 MISO |
| CPOL/CPHA 错 | SPI 模式与外设不匹配 | 按手册或课程配置模式 |
| Flash 写不进去 | 写入前没写使能 | 写/擦前调用 Write Enable |
| 写入后数据异常 | 擦除没完成或未等待忙标志清除 | 轮询忙标志后再读写 |
| 页写跨页异常 | 一次页写跨过页边界 | 按页拆分写入 |
| 气压换算不对 | 校准参数或补偿公式不匹配 | 先验证 ID 和原始值，再核对公式 |

### [[14_RGB灯与ESP8266|14 RGB 灯与 ESP8266]]

| 坑 | 原因 | 解决 |
|----|------|------|
| RGB 灯不亮 | 供电不足、数据方向接反或未共地 | 先点亮单颗灯并查电源/地线 |
| RGB 灯颜色乱 | 颜色字节顺序或缓冲区索引错误 | 核对颜色编码和灯珠顺序 |
| RGB 闪烁不稳定 | 单线时序不准或被中断打断 | 使用课程确认的定时方式 |
| ESP8266 无响应 | 波特率、TX/RX、供电或 EN/RST 状态不对 | 先用最小 AT 测试 |
| AT 指令无 OK | 换行格式错误或等待时间不够 | 按 `\\r\\n` 和课程延时测试 |
| 透传进得去退不出 | 退出序列和等待时间不对 | 先记录模块状态，再按固件规则退出 |
| 接收控制命令粘包/半包 | 串口不定长接收处理不完整 | 用 IDLE + DMA 或状态机分帧 |
| 能联网但控制无效 | 通信层和业务层混在一起 | 先打印原始命令，再解析执行 |

### [[15_RS485与CAN|15 RS485 与 CAN]]

| 坑 | 原因 | 解决 |
|----|------|------|
| RS485 只能发不能收 | 发送后未切回接收模式 | 等 UART TC 后再切 RE/DE |
| DE/RE 方向控制反了 | 收发器有效电平或接法理解错 | 查原理图并用示波器看方向脚 |
| A/B 线接反 | 差分线极性不匹配 | 交换 A/B 后重新测试 |
| RS485 长线不稳定 | 终端电阻、偏置电阻或拓扑不合理 | 按总线两端终端和偏置要求整改 |
| CAN 发不出去 | 没有其他节点 ACK 或波特率不一致 | 使用双节点或 CAN 分析仪确认 ACK |
| CAN ACK 错误 | 总线上无有效接收节点 | 接入同波特率节点并检查收发器 |
| 过滤器导致收不到 | 过滤器 ID/Mask 过窄或 FIFO 配错 | 调试阶段先放宽过滤器 |
| CANH/CANL 接反 | 差分线接错 | 交换 CANH/CANL 并复测 |
| 没有终端电阻 | 总线反射或电平异常 | 总线两端按规范加终端电阻 |

## 我的理解

踩坑日记最有价值的不是“我错了什么”，而是留下排查路径。

以后遇到问题时先按工程顺序排：

```text
电有没有
地有没有
线对不对
CubeMX 配没配
代码启动没启动
中断/DMA 有没有进
数据是不是按预期变化
```

这样比直接改代码靠谱得多。
