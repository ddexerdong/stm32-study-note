## 已收录的经典坑（按章节整理，供你实验时参考）

### 00 环境搭建

| 日期 | 问题 | 原因 | 解决 |
|------|------|------|------|
| | CubeIDE 编译报错 | 安装路径有中文 | 重装到全英文路径 |
| | 烧录不进去 | Debug 口未配 Serial Wire | CubeMX → SYS → Debug 选 Serial Wire |
| | 烧录后程序不运行 | BOOT0 悬空 | BOOT0 通过 10kΩ 电阻接 GND |
| | 重新生成代码后用户代码丢失 | 代码写在了 USER CODE BEGIN/END 之外 | 全部用户代码必须写在这对注释之间 |

### 09 GPIO

| 日期 | 问题 | 原因 | 解决 |
|------|------|------|------|
| | 按键按一下触发多次 | 没做消抖 | 加 20ms 延时或状态机消抖 |
| | LED 亮度异常/烧坏 | 没串限流电阻 | 根据 LED 参数计算并串接电阻（通常 220Ω~1kΩ） |
| | HAL_Delay 阻塞导致按键响应迟钝 | 在延时期间 CPU 无法读按键 | 改用定时器中断或状态机消抖方式 |

### 17 定时器与中断

| 日期 | 问题 | 原因 | 解决 |
|------|------|------|------|
| | 定时时间算出来不对 | 没考虑 APB1 的 ×2 规则 | 查时钟树确认 TIMx_CLK 实际频率 |
| | 中断回调永远不触发 | 用了 `_Start` 而不是 `_Start_IT` | 改用 `HAL_TIM_Base_Start_IT` |
| | 程序在中断里卡死 | 中断里调了 `HAL_Delay` | 中断里只用标志位/`HAL_GetTick`，耗时操作放 main 循环 |

### 19 串口 UART

| 日期 | 问题 | 原因 | 解决 |
|------|------|------|------|
| | printf 浮点数不显示 | 未加 `-u _printf_float` | CubeIDE 链接选项添加该参数 |
| | 中断接收只触发一次 | 回调里忘记重新调用 `Receive_IT` | 在回调末尾重新启动中断接收 |
| | 串口收到乱码 | 波特率不一致/没共地/TTL 电平不匹配 | 核对双方波特率，确认共地，确认 3.3V 电平 |
| | TX/RX 通信不通 | TX 接 TX，RX 接 RX 了 | 记住：自己的 TX 接对方的 RX（交叉连接） |

### 21 ADC

| 日期 | 问题 | 原因 | 解决 |
|------|------|------|------|
| | 多通道数据对不上 | buf 索引和 CubeMX Rank 顺序不一致 | adcBuf[0]=Rank1, adcBuf[1]=Rank2... |
| | ADC 读数一直为 0 或不准 | 未校准 | 启动前加 `HAL_ADCEx_Calibration_Start(&hadc1)` |
| | 传感器数值抖动大 | 采样时间太短/电源噪声 | 增大采样时间、加电容滤波、或软件多次取平均 |

### 22 PWM

| 日期 | 问题 | 原因 | 解决 |
|------|------|------|------|
| | PWM 引脚无输出 | 通道和引脚不匹配 / 忘了 `_Start` | 核实引脚重映射，确认已调 `HAL_TIM_PWM_Start` |
| | 舵机不转或抖动 | 供电不足（ST-Link 3.3V 带不动） | 舵机需外接 5V~6V 独立电源，共地 |
| | 占空比异常 | CCR 值超出 ARR | CCR 必须 ≤ ARR |
