# 踩坑日记

> 实验过程中遇到的问题和解决方法，按时间倒序记录。
>
> 目标：把“现象 -> 原因 -> 解决 -> 复盘”沉淀成可复用的工程经验。

---

## 记录模板

```text
日期：
章节：
实验：
现象：
原因：
解决：
复盘：
```

建议原则：

- 先写现象，不要一上来猜原因。
- 记录关键参数，例如波特率、PSC/ARR、引脚号、供电电压。
- 解决后补一句复盘，方便以后面试或复习时回忆。

---

## 总体排查顺序

```text
供电
-> 共地
-> 接线
-> CubeMX 配置
-> 初始化函数是否调用
-> HAL API 是否启动
-> 中断 / DMA / 回调是否进入
-> 业务逻辑
```

大多数入门问题不是算法错，而是电源、地线、引脚、模式、启动顺序错。

## 各章节经典坑速查

### 01 准备与基础认知

| 坑 | 原因 | 解决 |
|----|------|------|
| 烧录不进去 | `SYS -> Debug` 没配 `Serial Wire` | CubeMX 中打开 SWD |
| 烧录后程序不跑 | `BOOT0` 悬空或被拉高 | 正常运行时 `BOOT0` 下拉到 GND |
| 代码重新生成后丢失 | 写在 `USER CODE` 区域外 | 所有用户代码放入 `USER CODE BEGIN/END` |
| 定时器时间算不对 | 不知道真实 `TIMx_CLK` | 查 APB 分频和定时器 x2 规则 |
| 编译/路径异常 | 工具链或工程路径含中文、特殊字符 | 新手阶段使用纯英文路径 |

### 02 GPIO 与传感器

| 坑 | 原因 | 解决 |
|----|------|------|
| LED 不亮 | GPIO 模式、极性或限流电阻问题 | 先用万用表量 GPIO 电压 |
| LED/GPIO 烧坏 | LED 没串限流电阻 | 串 220 ohm~1 k ohm |
| 按键按一下触发多次 | 机械抖动 | 加 20 ms 延时或状态机消抖 |
| 按键状态一直不变 | 上拉/下拉和接线不匹配 | 上拉输入配按键接 GND |
| 蜂鸣器不响 | 有源/无源类型搞错或驱动不足 | 有源给电平，无源给 PWM，并加三极管 |
| GPIO 烧坏 | 蜂鸣器/继电器直接接 GPIO | 用三极管、MOS 或驱动芯片 |
| 传感器不触发 | 没共地、阈值没调、电平判断反了 | 量 DO 电压，调电位器，确认有效电平 |

### 03 中断与定时器

| 坑 | 原因 | 解决 |
|----|------|------|
| 定时器回调不触发 | 调了 `_Start` 而不是 `_Start_IT` | 使用 `HAL_TIM_Base_Start_IT` |
| 中断没进 | NVIC 没使能 | CubeMX 勾选对应中断 |
| 程序卡死在中断里 | 中断里调用 `HAL_Delay()` | 中断只设标志位，主循环处理 |
| 标志位主循环读不到 | 没加 `volatile` | 共享变量声明为 `volatile` |
| 定时时间不准 | 忽略 APB 定时器 x2 规则 | 重新计算 `TIMx_CLK` |
| EXTI PA0/PB0 冲突 | 同一 EXTI 线只能选一个端口 | 换不同编号引脚 |
| 按键 EXTI 触发多次 | 机械抖动边沿多次触发 | 时间戳消抖 |

### 04 串口与 DMA

| 坑 | 原因 | 解决 |
|----|------|------|
| 串口不通 | TX/RX 同名相接 | 交叉连接：TX -> RX，RX -> TX |
| 收到乱码 | 波特率不一致、未共地、5 V 电平 | 核对 115200/8N1、共地、3.3 V |
| `printf` 没输出 | 没重定向底层输出函数 | 实现 `__io_putchar` 或 `fputc` |
| `%f` 不显示 | 未开启浮点打印 | 链接选项添加 `-u _printf_float` |
| 中断接收只触发一次 | 回调里忘记重启接收 | 回调末尾重新 `HAL_UART_Receive_IT` |
| 定长接收一直不回调 | 没收到指定长度 | 改单字节命令或 IDLE + DMA |
| IDLE 不触发 | 没使能 `UART_IT_IDLE` | 调用 `__HAL_UART_ENABLE_IT` |
| DMA 后续不收 | 没重启 DMA | 处理完后重新 `HAL_UART_Receive_DMA` |
| 跨文件变量报错 | `it.c` 使用 `main.c` 变量未声明 | 在 `it.c` 中 `extern` |
| 中断里卡顿 | IRQ 中大量 `printf` 或发送 | 中断置标志，主循环处理 |

### 05 ADC 模数转换

| 坑 | 原因 | 解决 |
|----|------|------|
| ADC 值一直为 0 | 引脚没配 ADC、没启动、外部电压为 0 | 查 CubeMX、接线和启动函数 |
| 读数固定偏移 | 忘记校准 | 上电调用 `HAL_ADCEx_Calibration_Start` |
| 多通道数据错位 | Rank 和数组索引没对应 | 明确 `adcBuf[0]=Rank1` |
| 多通道只读最后一个 | 轮询读 DR 被覆盖 | 多通道使用 DMA |
| DMA 一轮就停 | Continuous 或 DMA Continuous Requests 没开 | CubeMX 打开对应选项 |
| 数据抖动大 | 采样时间短、电源噪声、源阻抗高 | 增大采样时间、加滤波、做平均 |
| 输入损坏风险 | ADC 引脚电压超过 3.3 V | 分压或限幅后再输入 |
| MQ 传感器前几分钟不准 | 传感器未预热 | 上电等待 2 分钟以上 |

### 06 定时器 PWM

| 坑 | 原因 | 解决 |
|----|------|------|
| PWM 无输出 | 忘记 `HAL_TIM_PWM_Start` | 初始化后显式启动 PWM |
| PWM 无输出 | 通道和引脚不匹配 | 查 CubeMX Pinout 和数据手册 |
| 占空比异常 | CCR 超过 ARR | 限制 CCR 范围 |
| 舵机不转/抖动 | 供电不足或未共地 | 外接舵机电源并共地 |
| 舵机角度不准 | 脉宽范围和舵机型号不匹配 | 查手册或实测标定 |
| 呼吸灯闪烁 | PWM 频率太低 | 提高到 1 kHz 以上 |
| CPU 被阻塞 | 用 `HAL_Delay` 做长渐变 | 改状态机或定时器节拍 |

### 07 TIM 触发 ADC

| 坑 | 原因 | 解决 |
|----|------|------|
| ADC 不触发 | TIM 没配 TRGO | `Trigger Output` 选 `Update Event` |
| ADC 不触发 | ADC 外部触发源选错 | 选对应 `Timer X Trigger Out` |
| 程序卡在 Poll | TIM 没启动或触发链路断 | 检查 TIM Start、TRGO、ADC Trigger |
| 采样节奏异常 | Continuous 和外部触发混用 | TIM 触发模式下关闭 Continuous |
| 前几次数据异常 | TIM 早于 ADC 启动 | 先 ADC Start，再 TIM Start |
| 温度比室温高 | 测的是芯片硅片温度 | 只当芯片内部温度参考 |
| `%f` 不输出 | 未启用浮点打印 | 添加 `-u _printf_float` |

## 我的理解

踩坑日记最有价值的不是“我错了什么”，而是留下排查路径。

以后遇到问题时先按工程顺序排：

```text
电有没有
地有没有
线对不对
CubeMX 配没配
代码启动没启动
中断/DMA 有没有进
数据是不是按预期变化
```

这样比直接改代码靠谱得多。
