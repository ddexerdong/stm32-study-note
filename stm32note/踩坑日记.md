## 各章节经典坑速查（预填，实验时对照核查）

### 01 准备与基础认知 [6]~[8]

| 坑 | 原因 | 解决 |
|----|------|------|
| 烧录不进去 | Debug 口没配 Serial Wire | CubeMX → SYS → Debug 选 Serial Wire |
| 烧录后程序不跑 | BOOT0 悬空 | BOOT0 通过 10kΩ 接 GND |
| 重新生成代码丢失 | 写在 USER CODE 之外 | 所有用户代码放在 BEGIN/END 之间 |
| 编译报错 | 安装路径含中文 | 重装到全英文路径 |
| 定时器时间算不明白 | 不知道 TIMx_CLK 实际值 | 去 Clock Configuration 确认 APBx 预分频和 ×2 规则 |

### 02 GPIO 与传感器 [9]~[16]

| 坑 | 原因 | 解决 |
|----|------|------|
| 按键按一下触发多次 | 没消抖 | 加 20ms 延时或状态机消抖 |
| `while(等待松开)` 卡死 | 松开前 CPU 无法做别的事 | 改用状态机消抖 |
| LED 烧坏 | 没串限流电阻 | 串 220Ω~1kΩ 电阻（按公式算） |
| 蜂鸣器不响/烧 GPIO | 没加三极管驱动 | 加 NPN 三极管 + 基极 1kΩ 电阻 |
| 传感器不触发 | GND 没共地 | 传感器 GND ↔ STM32 GND |
| 传感器一直触发 | 电位器阈值没调 | 用小螺丝刀拧模块蓝色电位器 |
| 传感器 DO 逻辑反了 | 不同模块有效电平可能不同 | 先拿万用表量 DO 脚电压确认 |

### 03 中断与定时器 [17]~[18]

| 坑 | 原因 | 解决 |
|----|------|------|
| 定时时间不对 | 没考虑 APB1 ×2 规则 | 去 Clock Configuration 确认 TIMx_CLK |
| 中断回调不触发 | 用了 `_Start` 而非 `_Start_IT` | 改用 `HAL_TIM_Base_Start_IT` |
| 程序卡死在中断里 | 中断里调了 `HAL_Delay()` | 中断里只用标志位 + `HAL_GetTick()` |
| 标志位 main 循环读不到 | 没用 volatile | `volatile uint8_t flag` |
| EXTI PA0 和 PB0 冲突 | 同一条 EXTI 线只能用一个引脚 | 换不同 EXTI 线的引脚 |
| 中断里变量值不对 | 编译器优化掉了重复读 | 加 `volatile` 关键字 |

### 04 串口与 DMA [19-x]~[20]

| 坑 | 原因 | 解决 |
|----|------|------|
| 通信不通 | TX 接 TX、RX 接 RX 了 | 交叉连接：TX↔RX, RX↔TX |
| 收到乱码 | 波特率不一致 / 没共地 / 5V 电平 | 核对波特率、共地、确认 3.3V |
| printf 浮点数不显示 | 未加 `-u _printf_float` | CubeIDE 链接选项添加 |
| 中断接收只触发一次 | 回调里忘记重新调 `Receive_IT` | 回调末尾重新启动接收 |
| IDLE+DMA 收不到 | 忘了使能 IDLE 中断 | `__HAL_UART_ENABLE_IT(&huart1, UART_IT_IDLE)` |
| IDLE+DMA 长度不对 | IDLE FLAG 清在 COUNTER 读取之后 | 先 CLEAR FLAG 再读 COUNTER |
| IDLE+DMA 后续不收 | 处理完忘了重启 DMA | `DMAStop` → `Receive_DMA` 重新启动 |
| 阻塞接收 CPU 卡住 | `HAL_UART_Receive` 死等 | 改用中断或 DMA 方式 |
| 跨文件变量未定义 | stm32f1xx_it.c 不识 main.c 的变量 | 加 `extern` 声明 |

### 05 ADC [21-1]~[21-5]

| 坑 | 原因 | 解决 |
|----|------|------|
| 读数一直为 0 或偏移 | 没校准 | `HAL_ADCEx_Calibration_Start(&hadc1)` |
| 多通道数据错位 | Rank 顺序和 buf 索引不对应 | adcBuf[0]=Rank1, adcBuf[1]=Rank2... |
| DMA 搬一轮就停 | Continuous Conversion 没开 | CubeMX 打开 Continuous Conversion |
| DMA 搬一轮就停 | DMA Continuous Requests 没开 | DMA Settings 里 Enable |
| 数据抖动大 | 采样时间太短 / 电源噪声 | 增大采样时间、加电容、软件取平均 |
| MQ 传感器前几分钟不准 | 没预热 | 上电后等 2 分钟以上再采 |
| 电压换算公式纠结 | /4095 还是 /4096 | 工程上用 /4095，差异可忽略 |
| 轮询方式只读到最后一个通道 | 多通道轮询不加 DMA | 多通道必须用 DMA |

### 06 定时器 PWM [22]~[23]

| 坑 | 原因 | 解决 |
|----|------|------|
| PWM 引脚无输出 | 通道和引脚不匹配 | 查数据手册、确认 `HAL_TIM_PWM_Start` 已调 |
| PWM 引脚无输出 | 忘了 `_Start` | 启动 PWM 必须调用 Start 函数 |
| 舵机不转 / 抖动 | 供电不足（ST-Link 3.3V 带不动） | 舵机需外接 5V~6V 独立电源，共地 |
| 占空比异常 | CCR 超出 ARR | CCR 必须 ≤ ARR |
| 呼吸灯闪烁 | PWM 频率太低 | 提到 1kHz 以上 |
| `__HAL_TIM_SET_COMPARE` 不生效 | 通道号写错 / 定时器未启动 | 确认 Channel 和 Start |
| 舵机角度不对 | 脉宽/角度非线性 | 查舵机手册，从小范围开始试 |

### 07 TIM 触发 ADC [24]

| 坑 | 原因 | 解决 |
|----|------|------|
| ADC 不触发 | 没配 TRGO | TIM → TRGO 选 Update Event |
| ADC 不触发 | Ext Trigger 没选或选错 | ADC → Ext Trigger → Timer X Trigger Out |
| 只触发了一次 | Continuous Conversion 误开了 | TIM 触发模式下关掉 |
| TIM 先于 ADC 启动 | 启动顺序反了 | 必须：校准→ADC_Start→TIM_Start |
| 温度值和室温差很多 | 正常！芯片内部温度 ≈ 室温 + 5~15℃ | 内部温度传感器测的是硅片温度 |
| printf 不输出 | 串口没配好 | 检查 USART1、波特率、`__io_putchar` |
