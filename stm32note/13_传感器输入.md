## 传感器类型速查

| 传感器 | 输出类型 | 读取方式 | 课程 |

| 光敏传感器 | DO（数字） | GPIO读取 | [13] |
| 反射传感器 | DO（数字） | GPIO读取 | [14] |
| 热敏传感器 | DO（数字）/ AO（模拟） | GPIO / ADC | [15] |
| 火焰传感器 | DO（数字） | GPIO读取 | [16] |

## 数字传感器原理

```
传感器模拟信号 → LM393比较器 → DO输出高/低电平
                     ↑
               电位器调节阈值
```

- 触发时：DO = LOW（接GND）
- 未触发：DO = HIGH（上拉）
- 不同型号可能有所差别

## 通用读取代码

```c
// 检测到触发（DO拉低）
if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_1) == GPIO_PIN_RESET) {
    // 触发操作：点亮LED / 响蜂鸣器
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);
} else {
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_RESET);
}
```

## 蜂鸣器（[12]）

### 有源蜂鸣器 vs 无源蜂鸣器

| | 有源 | 无源 |
|---|------|------|
| 内部 | 有振荡电路 | 无振荡电路 |
| 驱动 | GPIO高/低即可 | 需要PWM |
| 音调 | 固定 | 可变 |

### 有源蜂鸣器驱动

```c
// 响
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_8, GPIO_PIN_SET);
HAL_Delay(1000);
// 停
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_8, GPIO_PIN_RESET);
```

### NPN三极管驱动电路

```
STM32 GPIO → 1kΩ → 三极管B极
                    三极管C极 → 蜂鸣器 → VCC
                    三极管E极 → GND
```

> ⚠️ STM32 GPIO最大拉电流20mA，蜂鸣器电流较大，必须加三极管驱动
