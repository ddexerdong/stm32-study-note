# 13-16 传感器输入

> 本章涵盖常见的数字输出型传感器：光敏、反射、热敏、火焰。学完你就能用 GPIO 直接读取传感器状态。

## 传感器类型速查

| 传感器 | 输出类型 | 读取方式 | 课程 |
|--------|---------|---------|------|
| 光敏传感器 | DO（数字） | GPIO 读取 | [13] |
| 反射传感器 | DO（数字） | GPIO 读取 | [14] |
| 热敏传感器 | DO（数字）/ AO（模拟） | GPIO / ADC | [15] |
| 火焰传感器 | DO（数字） | GPIO 读取 | [16] |

> 💡 DO = 数字输出（Digital Output），只有高/低两种状态，一个 GPIO 就够。
> AO = 模拟输出（Analog Output），输出连续变化的电压，需要用 ADC 读取 → 详见 [21_ADC模数转换](21_ADC模数转换.md)。

## LM393 比较器原理（为什么传感器能输出数字信号）

```
传感器模拟信号 ──→ LM393 比较器 ──→ DO 输出高/低电平
                       ↑
                 电位器调节参考电压（阈值）
```

- **触发时**：DO = LOW（大部分模块拉低）
- **未触发**：DO = HIGH（模块上拉电阻保持高电平）

### 怎么调阈值？

模块上有一个蓝色的十字电位器，用小螺丝刀拧：

1. 接好 VCC 和 GND
2. 改变环境（比如光敏传感器用手遮光/松开）
3. 用万用表测 DO 脚电压 —— 调到「刚好在遮光时变低电平」就是你要的阈值

> ⚠️ 不同厂家模块的 DO 有效电平可能相反。**先不写代码，拿万用表量一下 DO 在有/无触发时的电压再写逻辑。**

## 通用接线

所有数字传感器模块接法都一样：

```
传感器模块                STM32
  VCC  ────────────────  3.3V（或 5V，看模块）
  GND  ────────────────  GND（必须共地！）
  DO   ────────────────  PA1（任意 GPIO 输入脚）
```

> 🔴 **必须共地**：传感器的 GND 和 STM32 的 GND 必须接在一起，否则 DO 信号没有参考，读出来的值毫无意义。

## 通用读取代码

```c
// 检测传感器触发（DO 拉低）
if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_1) == GPIO_PIN_RESET)
{
    // 触发操作：点亮 LED / 响蜂鸣器
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);
}
else
{
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_RESET);
}
```

> 传感器触发后状态可能很短暂（几毫秒），如果需要保持触发状态，用变量记录，不要只靠当前瞬间的读取。

## 蜂鸣器（[12]）

### 有源 vs 无源

| | 有源蜂鸣器 | 无源蜂鸣器 |
|---|----------|----------|
| 内部 | 自带振荡电路 | 纯线圈，无振荡电路 |
| 驱动方式 | GPIO 给高/低电平就响 | 必须给 PWM 信号 |
| 音调 | 固定单一频率 | 改变 PWM 频率可调音调 |
| 用法 | 报警提示音 | 播放旋律 |
| 价格 | 略贵 | 便宜 |

### 有源蜂鸣器驱动

```c
// 响
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_8, GPIO_PIN_SET);
HAL_Delay(1000);
// 停
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_8, GPIO_PIN_RESET);
```

### 为什么需要三极管驱动？

```
STM32 GPIO 最大输出电流 ≈ 20mA
蜂鸣器工作电流 ≈ 30~80mA

结论：GPIO 直接驱动可能烧引脚，必须用三极管做开关。

接线：
  STM32 GPIO → 1kΩ 电阻 → 三极管 B 极（基极）
                            三极管 C 极（集电极）→ 蜂鸣器 → VCC
                            三极管 E 极（发射极）→ GND

  GPIO 输出高电平 → 三极管导通 → 蜂鸣器得电 → 响
  GPIO 输出低电平 → 三极管截止 → 蜂鸣器断电 → 停
```

> ⚠️ 三极管不是可选的装饰品——电流超过 GPIO 承受能力会**永久损坏**芯片引脚。

## 传感器不触发时怎么排查？

按这个顺序来，一个环节一个环节排除：

1. **查供电**：万用表量 VCC-GND 电压，确认在模块额定范围内
2. **查 DO 电平**：万用表量 DO-GND，人为改变环境，看电压是否有高低变化
3. **查接线**：GND 共地了吗？IO 线是好的吗？杜邦线接触不良很常见
4. **查阈值**：电位器是不是拧到极限了？重新调节
5. **查代码**：GPIO 模式是输入模式吗？引脚号写对了吗？

## 踩坑记录

- [ ] 传感器和 STM32 没共地，DO 信号不对
- [ ] 电位器阈值没调好，一直触发或一直不触发
- [ ] 杜邦线接触不良（外表看不出来，量了才知道）
- [ ] AO 模拟输出用 GPIO 读不到有意义的值（需要用 ADC）
